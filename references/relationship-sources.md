# V0.4 感情资料与适用边界

本文件用于审计感情取用和流派差异，不要求每次分析加载。

## 传统资料

### 《奇门遁甲元灵经》卷十

婚姻占条目明确使用乙为女方、庚为夫方，并结合门、宫、日时干支等判断婚姻。这支持 RR-Y06，但文本建立在传统异性婚姻与夫妇角色框架上，不能无条件扩展到所有现代亲密关系。

- https://ctext.org/wiki.pl?chapter=636397&if=gb

### 《奇门遁甲秘笈大全》卷十

婚姻条目使用庚为男家、乙为女家、六合为媒妁，支持乙庚与六合的传统角色来源。这里的六合首先是媒介/和合条件，不等于现代心理学意义上的“爱情质量”。

- https://ctext.org/wiki.pl?chapter=86117&if=en&remap=gb

### 《奇门遁甲秘笈大全》卷十四

另一组婚姻占法以日干为男、时干为女，并要求兼看年命和类神。这与乙庚取法并行，支持 RR-Y07，也说明传统文本内部存在多层取用，不能宣称只有一套唯一婚姻用神。

- https://ctext.org/wiki.pl?chapter=890559&if=en&remap=gb

## 当前 Skill 的选择

1. 现代默认以具体人物 A/B 定义角色，不先按性别分配符号。
2. 日干为求测方；具体对方有可区分年命时以年命定位，否则时干作为对方/互动锚点。
3. 六合作为关系形成、连接或媒介条件；这是从传统媒妁/和合角色向现代关系层的解释扩展。
4. 乙庚仅在明确符合传统异性婚姻语境时作为辅助，并与具体人物身份交叉验证。
5. 任何符号都不能单独证明爱情、忠诚、性关系、出轨或隐私事实。

## 局限

- 古代婚姻制度、性别角色和现代亲密关系差异很大。
- 现存电子文本底本与作者归属并非总是完全明确；采用可核对条文，不把托名当作确定事实。
- V0.4 暂不提供第三者固定用神、桃花口诀、精确婚期或心理诊断。
- 规则只能形成术数框架下的关系倾向，仍需真实沟通和后续案例验证。
