# V0.5 商业财运资料与口径

本文件用于审计商业取用与传统分歧，不要求每次分析加载。

## 传统资料

### 《奇门旨归》

求财、贸易、交易、买货等分类条目使用日干、时干、甲子戊、生门和六合，并随买卖方向调整人物、货物与中介角色。它支持 CM-Y01 至 CM-Y05，也说明“时干代表什么”必须由具体问题决定。

- 书目入口：https://ctext.org/wiki.pl?if=gb&remap=gb&res=1642749
- 相关卷页：https://ctext.org/wiki.pl?chapter=7257249&if=en&remap=gb

### 《奇门遁甲秘笈大全》

相关贸易条文以日干为货主、时干为货物、甲子戊为资本、生门为利息，也有以日干为我、时干为他、六合为经纪的结构。这支持默认模型，但电子底本与作者归属并非完全明确，采用可核对条文而不把托名当作确定事实。

- https://www.xuanxuecenter.com/files/qi_men_dun_jia_mi_ji_da_quan_zhu_ge_wu_hou.pdf

### 《奇门遁甲元灵经》卷十七

贸易条目另以值符为买物之人、生门为货物/物主；合伙条目还使用生门天地盘区分财主与伙计。它证明传统体系内存在不同专题取法，支持 CM-YA01 作为备选，而不是与默认模型混算。

- https://ctext.org/wiki.pl?chapter=97793&if=gb&remap=gb

## 当前 Skill 的选择

1. 默认采用日干＝主体、时干＝对方/货物/事项、甲子戊＝资本、生门＝收益通道、六合＝中介/连接的模型。
2. 时干具体角色必须随买方、卖方、合作方、收款方等现实身份定义。
3. 《元灵经》的值符/生门天地盘方法作为传统备选，结论冲突时做双轨分析。
4. 生门从传统财利象扩展为现代收益、变现或收入通道；不能直接等同净利润。
5. 甲子戊表示资本基础，不等同现金安全、资产质量或偿债能力。

## 局限

- 古代贸易、货物与合伙制度和现代公司、证券、金融产品差异显著。
- V0.5 不建立具体资产类别的固定用神，也不提供交易信号。
- 传统规则不能证明投资有效性；金额、收益率和风险必须依靠现实数据与未来案例验证。
