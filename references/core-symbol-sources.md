# 核心符号资料与采用边界

本文件用于审计门、星、神、干及宫位综合规则，不要求每次分析加载。

## 传统资料

### 《遁甲演义》四库全书本

四库提要概括遁甲以九宫为本，配合三奇六仪、八门、九星及刑囚旺墓等结构。它支持“多层共同构成判断”的总体框架，但提要不等于完整占断字典。

- https://zh.wikisource.org/zh-hans/遁甲演義_(四庫全書本)

### 《奇门旨归》卷一、卷二、卷五

卷一列九宫八卦、九星、九神、三奇六仪、八门及干支五行等基础项；卷二明确一宫同时存在神、星、奇仪、门等克应，并要求结合得令失令、门宫生克和具体事项变通；卷五保存十干克应、九星克应和八门克应材料。

- 卷一：https://ctext.org/wiki.pl?chapter=360446&if=gb&remap=gb
- 卷二：https://ctext.org/wiki.pl?chapter=788235&if=gb&remap=gb
- 卷五：https://ctext.org/wiki.pl?chapter=230005&if=gb&remap=gb

采用边界：电子文本存在 OCR 和底本问题；克应常有特定占类语境，不能把一条古例扩展成所有现代问题的确定断语。

### 《奇门遁甲秘笈大全》

相关卷次分别保存值符、值使、十干、九星、八门及门迫等分类材料，支持各层需要同时观察、门迫作为组合修正的做法。

- 总入口：https://ctext.org/wiki.pl?if=gb&res=953105
- 卷十一：https://ctext.org/wiki.pl?chapter=292676&if=gb&remap=gb
- 卷十二：https://ctext.org/wiki.pl?chapter=71521&if=gb&remap=gb
- 卷二十二：https://ctext.org/wiki.pl?chapter=799331&if=gb&remap=gb

采用边界：作者归属和底本信息并不完全稳定；不同占类使用符号方式不同，只采用可交叉核对的结构原则。

## 当前规则选择

1. 采用“宫—门—星—神—干—旺衰—特殊状态—宫间关系”的分层综合法。
2. 古籍证明这些层需要共同观察，不证明任何现代固定权重或准确率。
3. 基础象意表属于现代解释层，用于稳定语言，不包装为古籍原文。
4. 具体十干克应和格局只有完成逐条来源核对后才升为传统规则；未核对条目不凭记忆补入。
5. 细节象意不得越过问题范围、安全边界和现实证据。
