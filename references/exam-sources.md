# V0.6 考试录取资料与口径

本文件用于审计考试取用与传统分歧，不要求每次分析加载。

## 传统资料

### 《奇门遁甲秘笈大全》卷九

科举条目同时使用丁奇、景门、天辅、日干、年命和值符，并讨论文章表现与主考取舍的关系。这支持把考生、文章/试卷、学习能力和评审权分层观察，而不是用一个符号包办全部结论。

- https://ctext.org/wiki.pl?chapter=652391&if=gb&remap=gb

### 《奇门遁甲秘笈大全》卷十二

相关条文有“日干为应试人、时干为主考”的角色结构，也使用值符、年命与值使等信息。这一取法保留为传统备选，不直接覆盖现代考试的默认结构。

- https://ctext.org/wiki.pl?chapter=71521&if=gb&remap=gb

### 《奇门遁甲元灵经》卷八

文武科举条目使用天辅、景门、星奇和值符；其中另见“值符主考、时干举子、景门策论”的结构。它与前述日干/时干分工并不相同，证明传统资料内部存在不同取法。

- https://ctext.org/wiki.pl?chapter=958139&if=gb&remap=gb

## 现代整理

### 《神奇之门》

现代考试论述常以日干为求测考生，并辅看丁奇文章、景门试卷、天辅和值符。V0.6 将它作为现代默认模型的参考，但不把现代教学归纳冒充古籍唯一原义。

- https://vr-d.com/pdf-file/%E5%A5%87%E9%97%A8%E9%81%81%E7%94%B2%2F/%E7%A5%9E%E5%A5%87%E4%B9%8B%E9%97%A8-%E5%BC%A0%E5%BF%97%E6%98%A5.pdf

## 当前 Skill 的选择

1. 现代问题默认采用：日干＝本人考生，时干＝本次考试/流程/结果事项。
2. 代问时日干仍表示求测者，目标考生优先以可区分年命定位。
3. 天辅＝学习与文教辅助，景门＝试卷及外显表现，丁奇＝文章、文字与表达辅助。
4. 值符只在评分、评委、主考或选拔权确实属于问题核心时作为评审层启用。
5. “日干应试、时干主考”以及“值符主考、时干举子”保留为传统备选；与默认模型冲突时分别输出，不混算，也不挑选较吉的一轨。
6. 结论依次区分准备、临场、答卷、通过、排名、录取和后续任用。

## 局限

- 古代科举与现代标准化考试、机器阅卷、院校录取和资格认证并非同一制度。
- 传统象意不能替代分数线、招生名额、资格审查、成绩单和官方通知。
- 本模块不根据宫数制造精确分数、排名或发布日期，也不把合成测试当作准确率证据。
