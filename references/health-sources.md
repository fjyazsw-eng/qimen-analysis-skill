# V0.7 健康模块资料与口径

本文件用于审计疾病取用、传统分歧和现代安全边界，不要求每次分析加载。

## 传统资料

### 《奇门遁甲元灵经》卷十二

疾病条目以天芮为病神，结合病者本命年干及生、死二门讨论病势。这说明患者与疾病信号需要分层，也表明古籍原文包含现代模块不能照搬的生死判断。

- https://ctext.org/wiki.pl?chapter=706534&if=gb

### 《奇门遁甲秘笈大全》卷八

占病条目使用天芮、日干、年命及生死门，并随天芮落宫讨论病势。V0.7 只吸收其“患者—疾病信号—病势参考”的结构，不采用具体疾病诊断、必死必生或寿数推断。

- https://ctext.org/wiki.pl?chapter=642938&if=en&remap=gb

### 《奇门旨归》相关疾病与请医条目

条文以病人日干为主、天芮为病神，并以天心和乙奇讨论医者及医疗能力。由于两者都可能承担医者含义，V0.7 将天心、乙奇保留为并列的医疗资源候选，不擅自固定成“医生/药物”唯一分工。

- https://ctext.org/wiki.pl?chapter=8134698&if=en&remap=gb

## 现代急救依据

国家卫生健康委员会的公众急救材料指出，昏迷、胸痛、呼吸困难、抽搐等急危重症表现，以及严重外伤、溺水、触电、中毒等情况，应立即拨打 120。V0.7 据此建立优先于术数分析的硬性安全分流。

- https://www.nhc.gov.cn/xcs/c100122/202405/f251e896a50a49ff8c632b4b3da93126/files/1734001844015_12363.pdf

## 当前 Skill 的选择

1. 本人患者默认用日干；代问时用可区分年命定位患者，日干保留为求测者。
2. 天芮只作传统疾病或不适信号，不能映射具体病名、器官或严重程度。
3. 天心、乙奇并列作为医者/医疗资源候选；没有明确体系依据时不拆成固定医生和药物。
4. 时干观察本次挂号、检查、治疗执行或随访事项，不替代患者和疾病信号。
5. 生门、死门只保留为受限的传统病势参考，废止字面生死、寿命和死亡日期判断。
6. 急症表现、检查、诊断、处方和医嘱在行动决策上始终高于盘面。

## 局限

- 传统文本的疾病类象形成于现代医学以前，不能验证病因、病理、疗效或预后。
- 本模块只能整理就医局势、资源、沟通与随访策略，不构成诊断或治疗。
- 合成测试只验证安全行为与分析边界，不证明健康预测准确率。
