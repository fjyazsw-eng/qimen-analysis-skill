# V0.2 取用资料与口径说明

本文件用于规则审计或流派争议，不要求每次分析加载。文本只记录会改变取用决策的资料，不把文献中的全部占法搬入 Skill。

## 传统资料

### 《遁甲演义》

明代程道生撰，维基文库据公开版本整理。书中明确列出六甲所遁六仪关系，支持 YS-J01 的甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸定位。它主要支持“如何在盘中定位甲”，不直接证明现代通用的日干/时干角色规则。

- 原文入口：https://zh.wikisource.org/zh/遁甲演義

### 《奇门旨归》

清代朱浩文编纂的分类占法资料。其求财、贸易、交易、买货等条目按具体问题分别使用日干、时干、戊、生门与六合，说明传统取用具有问题依赖性，不能压成一张万能表。用于支持 YS-RF01，并支持 V0.2 的“通用锚点 + 专题用神”结构。

- 电子文本入口：https://ctext.org/wiki.pl?chapter=7257249&if=en&remap=gb
- 书目信息参考：https://www.iwenyan.com/yijing/qimeizhigui

### 《奇门遁甲秘笈大全》卷十一

分类占法中的词讼部分明确使用日干、时干、值符和值使承担原告、被告、问官与事端等不同角色，支持 YS-RL01，也说明日时干的语义会随问题改变。现有电子版的作者归属和底本信息并不完全稳定，Skill 只采用可核对的条文，不把托名当作确定作者事实。

- 中国哲学书电子化计划：https://ctext.org/wiki.pl?chapter=292676&if=gb&remap=gb
- 可检索 PDF：https://www.xuanxuecenter.com/files/qi_men_dun_jia_mi_ji_da_quan_zhu_ge_wu_hou.pdf

## 现代通行口径

现代时家奇门教学中，“天盘日干为求测者、天盘时干为一般事体”使用广泛。本 Skill 将其定为 B 级默认，而不是声称它是所有古籍、所有专题唯一一致的规则。公开教学材料可作为该通行口径的旁证：

- https://www.zhaosir.online/Books/BookChapterDetail.aspx?did=1134
- https://www.d1peixun.com/m/view.php?aid=3009

## 当前选择与局限

1. 默认体系是传统时家拆补转盘法，取用落宫优先按天盘干。
2. 日干/时干是通用起点，不是专题规则的替代品。
3. 年命规则在传统与现代实践中的权重差异较大，因此本 Skill 将其限定为身份、代问、多人和长期事项层，不允许无条件替代日干。
4. 工作、感情等专项用神尚未完成来源对读，V0.2 不提前固化。
5. 文献规则只能证明“传统文本如何规定”，不能证明预测有效性；有效性仍需未来案例回归。
