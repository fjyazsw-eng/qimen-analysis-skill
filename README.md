# 奇门遁甲实战分析 Skill

一个面向长期迭代与真实案例回归的奇门分析 Skill。它不负责排盘，而是读取已经排好的结构化局式，稳定完成：输入核验 → 问题定义 → 取用 → 定性评价 → 状态与动力 → 未来预测 → 候选应期 → 决策趋避 → 前瞻冻结与复盘。

## 当前版本：V1.2.7

V1.2.7 是股票/ETF 十日预测的**时间轴冻结补丁**。

核心规则：

- 股票十日预测唯一时间锚点是**奇门起局时间**，不是用户后来提问的时间；
- 现实市场呼应核验只使用**起局时点及之前**的信息；
- 起局后、提问前已经发生的交易日仍属于原始十日窗口，只用于事后验证；
- 已发生日期不得删除，十日窗口不得整体向后滚动或重新补足；
- 起局后的真实行情、公告和结果不得反向修改原始九级定性、十日方向和关键转折。

股票图片继续遵守确定性渲染与冻结底稿规则：文字结论先冻结，图片只做机械可视化，不承担重新推理。

## 使用方式

提供已排好的结构化局式和明确问题即可。只发送盘面、尚未提问时，Skill 默认只确认收到并等待提问，不主动分析未问领域。

正式分析必须遵守[分析稳定性与冻结协议](rules/analysis-stability.md)：同一局式、同一问题、同一时间范围和同一版本，没有合法变化原因时，取用、主证据顺序、九级定性、主趋势、关键转折不得变化。

### 股票十个交易日预测

股票/ETF 内部完整执行取用、证据账本、逐日触发、现实市场核验和风险检查。时间轴执行顺序固定为：

`起局时点冻结 → 核验起局前现实信息 → 确认起局后十个实际交易日 → 独立生成原始十日预测 → 对已发生日期做事后验证 → 对未发生日期保留前瞻预测`

默认用户交付为：

1. **文字情况**：`【定性评价】 + 十日三列表（日期｜可能走势｜建议） + 关键提示`；
2. **六模块图片**：`当前行情｜奇门十日节奏曲线｜关键价格区域/观察信号｜十日情况简表｜卦象定性判断｜总体结论&关键提示`。

文字和图片必须来自同一冻结底稿。图片不得重新分析。

## 核心目录

- `SKILL.md`：总调度器
- `core/`：问题定义、输入核验、取用与通用 SOP
- `rules/`：宫位、旺衰、特殊状态、定性、应期、策略和稳定性规则
- `modules/`：职业、感情、商业财运、考试、健康、出行、寻人寻物、择时方位等专项
- `output/`：标准、简版、教学和复盘输出
- `cases/`：前瞻案例与预测台账
- `tests/`：合成场景和覆盖基线
- `scripts/validate_skill.py`：结构校验器

## 本地验证

```text
python scripts/validate_skill.py
```

验证器用于检查结构、链接、模块路由、版本与关键输出契约；验证通过不代表术数预测准确率已经得到证明。

## 维护原则

- 原始盘面、结构标注和综合推断分层保存，不静默改盘。
- 新规则不得只因单个成功案例进入核心；必须经过回归和前瞻案例验证。
- 同盘同问出现不同等级时，先判定是否存在合法输入变化；没有则按分析漂移处理。
- 事前分析与事后复盘分离；后验发现不得计入原预测命中。
- 医疗、法律、重大财务、人身安全等事项以现实安全与专业处理优先。
