# 奇门遁甲实战分析 Skill

一个面向长期迭代与真实案例回归的 Codex Skill。它不负责排盘，而是读取已经排好的结构化局式，稳定完成：输入核验 → 问题定义 → 取用 → 分层分析 → 证据整合 → 趋势与策略 → 后续复盘。

## 当前版本：V1.0

V1.0 已完成通用分析内核、全部专题模块、102 个合成测试场景、无依赖结构验证、人工验收量表和前瞻案例协议。此版本表示框架与工作流稳定，不表示奇门预测有效性已经得到真实案例验证。

**建设进度：100%（V1.0 发布基线）**。当前真实案例为零，预测有效性与准确率仍未验证。

## 目录

```text
qimen-analysis-skill/
├─ SKILL.md                 # Skill 总调度器
├─ agents/openai.yaml       # Codex 展示与调用元数据
├─ core/                    # 通用内核；yongshen/ 为 V0.2 取用规则库
├─ rules/                   # 可复用的结构分析规则
├─ modules/                 # 专项按需加载；含职业至择时方位的已启用模块
├─ output/                  # 输出与复盘模板
├─ cases/                   # 脱敏案例与案例格式
├─ scripts/                 # 无第三方依赖的结构验证
└─ tests/                   # 场景矩阵、覆盖基线与验收标准
```

## 输入约定

输入至少应包含起局时间、四柱、阴阳遁与局数、旬首、值符、值使，以及九宫中每宫的神、星、门、天盘干和地盘干。寄干、空亡、马星、旺衰及其他特殊结构应按“无 / 未提供 / 具体值”明确区分。完整字段见 [输入核验](core/input-validation.md)。

原始排盘、结构标注和 AI 推断必须分层保存。Skill 不会为了完成分析而重新排盘或补造缺失值。

## 使用方式

在 Codex 中调用 `$qimen-analysis-skill`，同时提供已排好的结构化局式、明确的现实问题、必要的人物关系/时间范围/已知事实；涉及多人区分或代问时，再提供相关年命信息。

## 本地验证

运行：

```text
python scripts/validate_skill.py
```

验证器不依赖 PyYAML，会检查 UTF-8、Skill 头信息、内部链接、模块路由、场景结构与唯一编号、覆盖基线、案例模板版本及未完成占位。它不能验证术数判断是否准确。

## 维护原则

- 新规则必须注明适用体系、证据来源或案例依据；存在流派差异时并列说明，不静默混用。
- 规则变更应先在脱敏历史案例上回归，再调整稳定内核。
- 事前分析与事后复盘分开保存，禁止用结果污染原始判断。
- 尚未选择开源许可证；发布后继续维护许可证选择、贡献规范和案例隐私策略。
