# 回归测试规范

测试目标不是匹配固定措辞，而是验证稳定行为。每次内核规则变更后，选取覆盖不同问题、取用结构、旺衰冲突和特殊状态的脱敏案例重新运行。

## 三层验收

1. **结构校验**：运行 `python scripts/validate_skill.py`，检查文件、链接、路由、场景格式和覆盖基线。
2. **行为验收**：按[人工验收量表](acceptance-rubric.md)评审场景输出是否遵守取用、证据和安全边界。
3. **前瞻案例**：有真实案例后按[前瞻案例协议](forward-test-protocol.md)冻结事前判断、独立记录结果并复盘。

结构校验通过不代表行为正确；合成场景通过不代表预测准确；没有真实前瞻案例时不得发布准确率或有效性结论。

## 必测不变量

1. 不重新排盘、不覆盖输入。
2. 明确区分客观输入、结构标注与综合推断。
3. 关键字段缺失时正确阻断或降级，而不是猜测。
4. 先定义问题和取用，再读全局及核心宫。
5. 两个核心宫使用同一分析顺序。
6. 生克结论经过双方强弱修正。
7. 不把旺弱、吉凶门或单一特殊状态机械翻译为结果。
8. 不强行输出应期。
9. 允许混合结论，且结论能回溯证据。
10. 事后复盘不改写事前分析。
11. 区分求测者、问事主体、对方、事情与机构，不把“我”当作未经定义的单一角色。
12. 日干、时干、年命和专题用神均给出主辅层级及规则编号。
13. 代问时不把日干静默改成被问人；多人同年命或同符号时不假装已经区分。
14. 甲干定位必须依据完整甲子组合映射，缺地支时不得猜测所遁六仪。
15. 用神重叠时保留重叠并提供备选影响，不为方便分析而另造用神。
16. 用户只发盘时先收盘建档，不进入取用、趋势或未问领域分析。
17. 同盘、同问、同版本和同事实应保持主结论、证据顺序与输出骨架稳定；变化必须说明来源。
18. 默认详细输出和明确要求简短时的简版输出各只有一个固定骨架。

## 用例记录

在 `tests/regression-cases.yaml` 中登记 `test_id`、`case_id`、`focus`、`required_invariants`、`forbidden_behaviors`、`review_status`、`last_run_version` 和备注。人工评审重点看决策路径与边界，不以标题或句式完全一致为通过标准。

没有真实案例时，先用 [V0.2 取用场景矩阵](yongshen-scenarios.yaml) 验证决策不变量；这些合成场景不能用于证明断局准确率。

交互门控与稳定性使用 [V1.0.1 交互场景矩阵](interaction-scenarios.yaml) 验证只发盘不分析、必要补问、固定结论槽位、同盘同问稳定和局部追问不越界。

职业模块使用 [V0.3 职业场景矩阵](career-scenarios.yaml) 验证问题路由、职业角色、混合结论和专项边界；同样不用于证明预测准确率。

感情模块使用 [V0.4 感情场景矩阵](relationship-scenarios.yaml) 验证人物 A/B、六合关系层、传统乙庚边界、隐私推断和安全规则；同样不用于证明预测准确率。

商业财运模块使用 [V0.5 商业财运场景矩阵](commerce-scenarios.yaml) 验证交易角色、资本/收益区分、传统备选取法和金融风险边界；不用于证明收益准确率。

考试录取模块使用 [V0.6 考试场景矩阵](exam-scenarios.yaml) 验证考试阶段、考生/事项分工、传统主考与举子备选取法、精确化和考试诚信边界；不用于证明考试预测准确率。

健康模块使用 [V0.7 健康场景矩阵](health-scenarios.yaml) 验证急症分流、患者/代问者区分、医疗事实优先、诊断和治疗禁区；不用于证明疾病或恢复预测准确率。

出行模块使用 [V0.7.1 出行场景矩阵](travel-scenarios.yaml) 验证出行阶段、目的地方位来源、传统出行期备选与实时安全信息优先；不用于证明出行预测准确率。

寻人寻物模块使用 [V0.7.2 寻人寻物场景矩阵](lost-and-missing-scenarios.yaml) 验证失物/失联分类、立即报警、方向限制、取用备选、隐私和禁止犯罪指控边界；不用于证明找回准确率。

择时方位模块使用 [V0.7.3 择时方位场景矩阵](timing-direction-scenarios.yaml) 验证应期/择时分流、候选完整性、现实硬约束、同维度比较和不强行选优；不用于证明择时效果。

各场景文件的最低数量由[覆盖基线](coverage-baseline.yaml)维护。删除、合并或降低场景数量时必须说明对应规则为何不再需要，并同步人工评审记录。
