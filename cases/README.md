# 案例规范

每个案例单独存放在 `cases/<case_id>/`，至少包括：`case.yaml`、原始输入、事前分析、prediction-ledger、实际结果和复盘。

案例必须在结果未知时冻结。`case.yaml` 使用 `skill_version: "1.2.4"`，并记录问题、目标事件、取用、定性、应期、失效条件与隐私状态。

同盘同问建议在预测台账同时保存 `analysis_fingerprint` 和 `evidence_ledger`，用于跨对话一致性检查。新局、新事实或现实行情更新只能追加修正，不得覆盖旧预测。

结果出现后再登记 outcome 和 review。事前没有提出、事后才发现的依据必须标为【后验发现】，不得计入原预测命中。

案例进入公开仓库前必须脱敏。无法验证的反馈标为主观反馈，不得作为强回归证据。
