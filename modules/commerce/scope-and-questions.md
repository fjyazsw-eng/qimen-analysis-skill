# 问题与财务口径

先识别问题属于哪条路由，并定义可验证目标。

| 路由 | 必须明确 |
|---|---|
| 生意/合作 | 谁出资、谁执行、谁决策；问意愿、合作、盈利还是落地 |
| 交易/谈判 | 用户是买方还是卖方；标的、对方、中介、合同阶段 |
| 收入/现金流 | 工资、副业、经营收入、回款或借贷；时间范围 |
| 投资 | 资产类别、持有期限、风险承受、问趋势还是决策条件 |

“财运如何”默认不能直接分析。至少明确收入来源和时间窗口；当前收入、商业利润和投资收益必须分开。

“能不能赚钱”必须定义是收入增加、成交、毛利、净利润、到账还是资产升值。项目能执行属于职业/项目模块，项目能盈利属于本模块，两者可以分别成立。

已知事实单列：投入金额、成本、报价、合同、付款条件、债务、现金余额、市场价格、监管限制。盘面不覆盖这些数据。
