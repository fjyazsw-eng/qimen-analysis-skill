# 股票未来十个交易日预测

本规则用于用户明确询问某只股票、ETF 或可交易证券未来十个交易日的盘面趋势。它借鉴六爻实战报告的“先定总体、再按时间轴逐日列触发与结果”格式，但底层判断仍统一使用奇门取用、宫位、门星神干、旺衰、生克、特殊状态和应期证据；不得把六爻世应、六亲、日月建或动爻规则改名后套入奇门。

## 一、最低输入

- 标的名称、代码和交易所；不能只写“这只股票”。
- 起局时间、完整结构化奇门局式和明确问题。
- 预测起点：从下一个交易日开始，还是包含尚未收盘的当日。
- 可核验的交易日历、停牌信息；没有可靠日期时只写 `T+1～T+10`，不得把周末、休市日或停牌日编成交易日。
- 当前价格、近期走势、成交量和重大已知事件属于现实参照层；缺少时仍可做术数趋势预测，但必须降低置信度，不能虚构价位或百分比。

## 二、目标事件与取用

目标事件固定为“未来十个实际交易日内该标的每日收盘方向、日内强弱与阶段转折倾向”，不是用户账户盈亏，也不是具体买卖指令。

- 日干：求测者/决策主体，只用于承载和风险适配。
- 时干：本次标的或交易事项主用；角色必须明确。
- 生门：收益与价格上行通道。
- 甲子戊：资金、承接与量能基础。
- 值符、值使及相关门星神干：市场主导力量、执行通道和表现方式的修正。
- 现实价格、量能、公告和指数环境：独立现实证据层，不得伪装成盘面事实。

预测标的走势时，必须以“标的/事项主用 + 生门 + 资金承接 + 宫际动力”为核心，不能只分析日干，也不能只见生门便断上涨。

## 三、十日推演方法

1. 先给十日总体路径：`持续偏强 / 先强后弱 / 先弱后强 / 区间整理 / 持续偏弱 / 高波动转折`，只能选择一个主路径。
2. 依[通用应期系统](../../rules/timing.md)检查 T+1～T+10 对核心宫和事件链的逐日触发。日期干支或交易日历不可靠时，只能保留序号，不得伪造每日触发。
3. 连续数日信号应组成“蓄势 → 启动 → 加速 → 转折 → 整理/兑现”的阶段链，不把十行写成互不相干的十次占断。
4. 每个交易日必须给一个首要方向，不能同时列涨跌两套结果；冲突证据通过降低置信度和写明关键验证线处理。
5. 十日内最多标记三个关键节点：最可能启动日、最可能转折日、风险最高日。证据不足时少标，不凑数。

## 四、统一方向词表

逐日“方向”只能使用以下五类：

- **强势上行**：上行动力占明显优势，预计收盘方向偏上且波动可能放大。
- **偏强整理**：偏上或抗跌，但推进力度有限。
- **横盘整理**：方向优势不足，主要表现为区间消化；不得把它当作逃避判断的默认项。
- **偏弱整理**：承接不足或压力偏强，预计收盘方向偏下但未形成明显加速。
- **明显下行**：下行动力占明显优势，预计收盘方向偏下且风险可能放大。

“方向冲突”“有涨有跌”“注意波动”不能单独充当方向结论。实在无法形成方向时必须直写“证据不足，无法可靠判断”，说明缺失项，不伪装成横盘整理。

强度只能使用 `强 / 中 / 弱`；置信度继续使用 `高 / 中高 / 中 / 中低 / 低`。方向、强度和置信度是三个不同维度，不得混写。

## 六、准确表达与现实边界

- 方向必须明确，但不能使用“一定涨、必跌、百分之百”。
- 没有可靠价格模型时，不报具体价位、涨跌幅、涨停或跌停概率。
- 不因用户持仓成本改变盘面方向结论；账户盈亏与标的走势分开。
- 不直接给买入、卖出、加仓、减仓、做多、做空、仓位或杠杆指令。
- 可以给观察、核验、风险暴露和失效条件；现实公告、停复牌、财报、监管和市场数据优先。
- 同一盘、同一标的、同一预测起点的十日表必须保持稳定；新信息或新局出现时按多局规则追加修正，不覆盖旧表。
