# 股票未来十个实际交易日预测

本规则用于用户明确询问股票、ETF 或其他可交易证券未来十个实际交易日走势。底层只使用奇门取用、宫位、门星神干、旺衰、生克、特殊状态、应期与现实市场证据；六爻只可借鉴逐日时间轴的表达形式，**不得把六爻世应、六亲、日月建或动爻规则混入奇门证据链**。

## 一、前置门槛

正式十日预测前必须先核验：标的名称/代码/交易所、最新行情与数据时间、近期量价、板块或指数相对强弱、重大公告/停复牌/监管事项，以及未来十个实际交易日。

正式用户日期必须使用**具体日期 + 星期**。若无法联网或无法可靠确认交易日历，只能给总体趋势草案，不得编造正式十日表、价格、涨跌幅、停牌状态或日干支。

## 二、固定取用与证据链

股票走势的核心证据固定为：

- 标的/交易事项主用；
- 生门：收益与上行通道；
- 甲子戊：资金、承接与量能基础；
- 值符、值使及核心宫：主导力量和落实通道；
- 宫际生克、资源流向、旺衰与特殊状态：用于综合修正；
- 现实行情：独立现实层，不伪装成盘面事实。

不得只看日干、只见生门、只见吉门/凶门，或只凭空亡、入墓、击刑、门迫、伏吟、反吟、马星决定最终方向。

## 三、分析稳定性

股票专项强制遵守[分析稳定性与冻结协议](../../rules/analysis-stability.md)。

正式分析顺序固定：

`分析指纹 → 取用 → 证据账本 → 五问方向闸门 → 卦象九级定性 → 十日主趋势 → 每日独立触发 → 十日逐日方向 → 现实市场比对 → 用户建议 → 图片冻结字段`

后一步不得反向改写前一步。

### 同盘同问强制规则

同一局式、同一标的、同一预测起点、同一问题范围、同一 Skill 版本：

- 取用必须相同；
- 主支持/主阻力证据顺序必须稳定；
- 九级卦象定性必须相同；
- 十日主趋势、关键转折与逐日原始方向必须相同。

只有盘面更正、主体/目标/范围改变、新局修正或版本规则实质变化时才允许改变；否则视为**分析漂移**，必须回退到既有冻结结论。

现实行情变化、用户成本和持仓只允许影响现实比对、关键区域和行动建议，不得把同一卦象从“平偏凶”改成“平偏吉”，也不得反向改写已经冻结的十日原始方向。

## 四、逐日推演

未来十个实际交易日必须逐日推演，每一天独立检查日期干支对标的主用、生门、资金宫、核心宫及事件链的触发，并综合生克、冲合、刑墓、空亡填实/冲空、马星等。

禁止：

- 从“先弱后强”等总体趋势机械分配每日涨跌；
- 为了曲线好看人为平滑；
- 只凭单一日干、冲合或五行关系定方向；
- 把休市日、周末或停牌日排入十日表。

证据不足时直写“证据不足，无法可靠判断”，不得用横盘整理掩盖缺失。

## 五、统一方向词表

逐日方向只允许：

- **强势上行**
- **偏强整理**
- **横盘整理**
- **偏弱整理**
- **明显下行**

方向、强度和置信度是不同维度。默认用户简表只显示方向，不把内部置信度和证据列堆给用户。

## 六、V1.2.4 稳定化固定交付（最高优先级）

本节覆盖旧版股票输出描述，也覆盖通用详细/简版模板对股票用户可见层的要求。内部仍必须完整执行 SOP，但默认用户交付**固定只有两个部分：第一部分文字情况 + 第二部分固定六模块图片**。

### 第一部分｜文字情况

固定顺序如下，不得改名或临时增删一级栏目：

```markdown
【定性评价】
等级：九级原文
一句话：
核心判断：
建议：

【未来十个实际交易日】
| 日期 | 可能走势 | 建议 |
|---|---|---|
| YYYY-MM-DD 周X | 五级方向原文 | 简短观察/风险动作 |
| ...共十行... | | |

【关键提示】
- 重点日期：最多 3 个
- 总体节奏：一句话
- 现实冲突/失效条件：存在时才写
```

硬约束：

- 十日表恰好十行实际交易日；
- “可能走势”必须逐字来自冻结五级方向；
- 九级等级是冻结的**卦象定性**；
- 默认不展开取用、宫位、逐日干支触发、置信度、现实市场快照或奇门×现实比对；用户明确要求“详细分析/教学/依据”时再展开；
- 详细展开只能解释已冻结结论，不得重新生成另一套定性或十日方向。

### 第二部分｜固定六模块图片

除非用户明确说“不要图片/只要文字”，正式股票十日预测在具备图片能力时必须同时生成一张横向 16:9 金融仪表盘。**六个模块必须全部存在、名称和职责固定：**

1. **当前行情**：数据截止时间、最新价、当日涨跌、今开/最高/最低、量价信息；只使用已核验行情。
2. **奇门十日节奏曲线**：横轴使用同一份十个实际交易日；由冻结方向/强度映射成相对节奏，并注明“相对强弱节奏，不是股价预测”。
3. **关键价格区域**：有可靠现实价格依据时展示防守区、第一压力区、强压力区、用户成本背景等；无可靠价格依据时模块标题改为**关键观察信号**，严禁编造价位。
4. **未来十个交易日情况简表**：与文字底稿同源，固定 `日期｜星期｜可能走势｜建议`，十行完整。
5. **卦象定性判断**：逐字复制文字部分的九级等级、同一句话和核心判断；不得用星级、近义词或图片模型另起第二套判断。
6. **总体结论 & 关键提示**：总体节奏、重点日期、失效条件、现实风控/操作原则，与文字部分一致。

视觉骨架固定：深蓝总标题栏 + 白底主体 + 红色模块标题；上半区三栏为模块 1～3，下半区左侧模块 4，右侧依次模块 5～6。固定的是六模块信息架构，不要求像素级一致。

## 七、内部详细字段

内部分析仍保留并可在用户要求详细过程时展开：

- 【现实市场快照】
- 【奇门十日总览】
- 【奇门 × 现实比对】
- 【未来十个实际交易日逐日预测】

这些字段是内部证据与教学层，不再作为默认用户正文。

## 八、零推理图片协议

图片生成前必须先冻结白名单字段：标的名称/代码、局式时间、行情数据时间与数字、九级定性原文、十个交易日期、每日方向、每日建议、重点日期、关键价格区域/观察信号、总体结论。

图片模型只负责排版，**零推理、零补全、零改写**。不得：

- 改变九级等级；
- 改变任何一天方向或建议；
- 新增、删除或错排日期；
- 编造目标价、止损价、涨跌幅、仓位或星级结论；
- 根据视觉美观重排预测节奏；
- 用用户成本价反推目标价或盘面方向。

发布前逐项核对：`定性等级 → 十个日期 → 十日方向 → 十日建议 → 重点日期 → 关键区域/观察信号 → 总体结论`。任一项冲突即判图片无效并重生成；无法可靠校验时宁可只交付准确文字。

## 九、金融边界

- 不使用“一定涨、必跌、百分之百”。
- 没有可靠价格模型时，不报目标价、涨跌幅或涨跌停概率。
- 不因持仓成本改变标的原始走势判断。
- 不把术数预测包装成确定性买卖、仓位或杠杆指令。
- 现实公告、停复牌、财报、监管和市场数据优先用于风控。
- 新行情只能追加现实修正；新局按多局规则追加新局修正，不覆盖旧预测。
