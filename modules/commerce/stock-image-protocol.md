# 股票六模块图片固定协议 V1.2.6

本文件是 `stock-ten-day-forecast.md` 的图片执行层。正式股票/ETF十日图必须采用确定性程序化渲染，以 `assets/stock-dashboard-template.svg` 为官方六模块视觉骨架。

## 最高优先级

固定顺序：`完整SOP分析 → TEXT_FREEZE → 用户可见文字正文 → IMAGE_PAYLOAD → 程序化渲染六模块PNG → 字段验收 → 以下载附件链接发布PNG`。

`TEXT_FREEZE` 是唯一权威结果。图片只是冻结正文的可视化副本，不是第二次分析。严禁制图层直接读取九宫原盘重新推演。

## 六模块锁定

必须且只能包含：
1. `一、最新行情`
2. `二、奇门十日节奏曲线（未来十个交易日）`
3. `三、关键价格区域（元）`；无可靠价位时改为 `三、关键观察信号`
4. `四、未来十个交易日操作计划表`
5. `五、卦象定性判断`
6. `六、综合结论`

禁止生成九宫格、奇门盘、八门九星说明图、宫位分析框或额外模块。

## IMAGE_PAYLOAD

程序化渲染器只能读取冻结后的白名单字段：证券名称/代码、起局时间、行情数据时间、最新行情、九级定性、一句话、核心判断、恰好十个实际交易日及其五级方向/强度/rhythm_score/观察点/现实价位/建议、关键价格区域或观察信号、成本持仓背景、重点日期、总体节奏、失效条件、风险原则和置信度。

十日方向逐字使用冻结结果。曲线固定映射：强势上行 `+2`、偏强整理 `+1`、横盘整理 `0`、偏弱整理 `-1`、明显下行 `-2`；曲线注明 `相对强弱节奏，不是股价预测`。关键价位只能来自已核验现实行情，缺失字段留空，禁止制图层补全。

## 正文优先与确定性渲染

**禁止用生成式图片模型生成正式股票仪表盘中的证券名称、数字、日期、价格、方向、表格文字和曲线点。** 有文件生成能力时，优先使用 Python/PIL、HTML/SVG 等确定性程序化方式生成 PNG，并通过文件附件/下载链接交付；不得用图片工具调用覆盖或隐藏正文。

若当前环境没有程序化制图/文件附件能力：完整交付文字正文，可附 IMAGE_PAYLOAD，但不得退回生成式图片模型伪造正式图。图片失败不触发重新分析，不改变 TEXT_FREEZE。

## 官方模板

`assets/stock-dashboard-template.svg` 只负责视觉布局：横向16:9、深蓝总标题栏、白底主体、红色模块标题、上三栏、下方左侧十日表、右侧定性与综合结论。模板示例数据不得进入新预测。

## 发布前验收

必须检查：横向16:9；六个一级模块全部存在且只有六个；标的名称/代码正确；行情数字与数据时间来自 IMAGE_PAYLOAD；十个日期恰好十个且顺序一致；每日方向、曲线点、九级定性、重点日期、关键区域、总体结论与 TEXT_FREEZE 一致；没有新增目标价、涨跌幅、仓位、杠杆或保证性结论。任一失败，只交付文字，不发布错误图片。

仓库提供 `scripts/render_stock_dashboard.py` 作为参考确定性渲染器。不同环境可重写渲染实现，但不得改变上述数据协议和交付顺序。
