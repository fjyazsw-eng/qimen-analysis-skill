## 固定证据链

1. **主体**：日干或按 V0.2 定位的实际决策人。
2. **具体事项/对方/货物**：时干，其角色由问题方向决定；不可含糊兼任而不说明。
3. **资本/本金**：甲子戊，回答投入与资本承载，不等于利润。
4. **收益通道**：生门，回答收益机会如何表达，不等于净利润或必赚。
5. **中介/连接**：六合，仅在经纪、撮合、合作连接确实存在时启用。
6. **现实财务层**：价格、成本、现金流、合同、概率和风险控制来自现实数据，盘面不能替代。

## 禁止

- 生门旺就断一定赚钱，戊旺就断资金充足且安全。
- 把营业收入、毛利、净利润、回款和账面估值混成“财”。
- 未确认用户是买方、卖方、出资方或收款方就分配交易角色。
- 把六合固定为所有合作伙伴，或据玄武等象意指控诈骗。
- 用一个时干同时代表客户、货物、合同和项目，却不记录角色重叠。
- 给出仅凭奇门的股票/基金买卖、杠杆、仓位或收益保证。
- 在缺少成本、合同、信用、流动性和现实证据时制造精确金额与日期。
- 股票预测只给笼统的“震荡、注意风险”，却不按固定十日表给出每日首要方向。
- 为了显得确定而虚构交易日、日干支、价位、涨跌幅或日内路径。
