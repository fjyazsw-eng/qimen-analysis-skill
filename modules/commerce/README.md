## 固定证据链

1. 主体：日干或按 V0.2 定位的实际决策人。
2. 具体事项/对方/货物：时干，其角色由问题方向决定。
3. 资本/本金：甲子戊，不等于利润。
4. 收益通道：生门，不等于净利润或必赚。
5. 中介/连接：六合，仅在确有连接关系时启用。
6. 现实财务层：价格、成本、现金流、合同、概率和风险控制来自现实数据，盘面不能替代。

## 禁止

- 生门旺就断一定赚钱，戊旺就断资金安全。
- 把营业收入、毛利、净利润、回款和估值混成“财”。
- 未确认交易角色就分配买卖关系。
- 给出仅凭奇门的保证性股票买卖、杠杆、仓位或收益承诺。
- 股票预测只给笼统震荡而不核验现实市场、实际交易日和逐日方向。
- 虚构交易日、日干支、价位、涨跌幅或日内路径；或从总体趋势机械平滑十日涨跌。
- **正式股票六模块图不得用生成式图片模型绘制数字、日期、价格、表格和曲线；必须正文先显示，再程序化渲染 PNG 并以附件/下载链接交付。**
