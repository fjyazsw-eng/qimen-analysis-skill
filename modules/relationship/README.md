## 固定证据链

1. **人物 A**：求测者或问事主体，通常为日干。
2. **人物 B**：具体对方；优先使用可区分年命，否则按一对一问题以时干为对方/互动锚点。
3. **关系本身**：六合作为结合、连接或媒介条件；传统原义偏媒妁与和合，现代“关系状态”属于扩展解释。
4. **互动过程**：时干未承担人物 B 的唯一定位时，用于当前联系、推进或所问事项；若兼任双方角色，声明重叠。
5. **承诺与现实条件**：只在问题涉及婚姻、公开、家庭或制度约束时加入相应候选，不凭空创建。

感情结论必须分开：情绪/好感倾向、实际行动、关系形成、长期承诺。四者不能互相替代。

## 禁止

- 未经用户说明，假定双方性别、性取向或婚姻角色。
- 把乙庚传统男女取法机械套到所有现代关系。
- 仅凭六合、玄武、天蓬、桃花类象断定爱、出轨、性关系或隐私事实。
- 把生克直接翻译成“谁更爱谁”。
- 声称准确读取对方内心，或保证复合、结婚、分手。
- 鼓励监控、试探、操纵、纠缠或绕过对方边界。
- 遇到暴力、胁迫、跟踪或人身风险时仍只谈盘面。
