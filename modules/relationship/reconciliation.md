# 分手与复合

## 先定义复合

区分重新联系、恢复见面、口头和好、正式恢复关系以及长期稳定。用户未定义时，不把一次联系当作复合成功。

## 分析顺序

1. A、B 当前是否具备接触与回应能力。
2. 六合是否仍有连接或重新建立关系的条件。
3. 时干是否支持实际联系、沟通和推进。
4. 原分手原因是否在现实中改变；盘面不能替代这一事实。
5. 伏吟、反吟、空亡等只修正停滞、反复或落实程度。

## 边界

反吟可能表示来回、反复或重新触发，也可能继续不稳定，不能直接译成“会复合”。伏吟可能表示旧模式持续，不能直接译成“永远没机会”。若对方已明确拒绝联系，策略必须尊重边界，不因盘面倾向鼓励纠缠。
