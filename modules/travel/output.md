# 出行问题输出

以下内容映射到[通用十二段模板](../../output/standard-analysis.md)的对应一级栏目，不得作为另一套正式一级结构；即时安全信息先于术数定性。

## 1. 行程定义

- 旅行者及代问关系：
- 起点、目的地与相对方位：
- 时间窗口、交通方式和返程计划：
- 出行目的与成功标准：

## 2. 现实核验

- 官方安全/天气/灾害信息：
- 交通与口岸状态：
- 证件、健康、资金和住宿：
- 尚未核验项：

## 3. 取用记录

- 旅行者（日干/年命）：
- 行程（时干）：
- 目的地/路线宫及方位来源：
- 开门、马星：
- 传统备选是否启用：

## 4. 分阶段结论

- 启程：
- 途中：
- 抵达与停留：
- 出行目的：
- 返程：

## 5. 策略与边界

- 可提前准备、核实或预留的资源：
- 改签、备用路线和紧急联系安排：
- 哪些结论仍需实时信息确认：

结尾说明：术数分析不能保证交通或人身安全；实时官方预警、承运方信息和当地法律指引优先。
