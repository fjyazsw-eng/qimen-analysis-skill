# 问题范围与阶段

## 必须明确

| 项目 | 内容 |
|---|---|
| 旅行主体 | 谁真正出行，是否为代问 |
| 起点与目的地 | 实际地点及相对方位 |
| 时间窗口 | 计划出发、抵达、停留和返程时间 |
| 交通方式 | 飞机、铁路、自驾、船舶、步行或组合 |
| 出行目的 | 旅游、工作、探访、搬迁、就医等 |
| 成功标准 | 成行、按时到达、办成事情还是安全返程 |

“这趟能不能去”至少拆成：现实是否允许、能否启程、途中是否顺畅、能否到达、目的能否实现、能否按计划返程。

## 不同问题不得混用

- **出行**：未来是否启程及过程。
- **行人**：已经在外的人何时回来，属于返程/行人问题。
- **迁移**：长期居住或搬迁，还需要考虑住所、工作和现实手续。
- **择时择方**：只有用户明确需要且具备候选时间盘/路线时，才调用[择时方位模块](../timing-direction/README.md)；不自动生成吉时吉方。
