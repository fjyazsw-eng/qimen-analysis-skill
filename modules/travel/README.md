## 固定证据链

1. **现实可行性与安全**：官方预警、天气、交通、边境、证件、健康和资金。
2. **旅行主体**：本人通常为日干；代问按 V0.2 以年命定位实际旅行者。
3. **本次行程**：时干观察旅行事项和过程。
4. **目的地/路线条件**：按现实起点到目的地的方位确定宫位，不凭地名猜测。
5. **启程与通行**：开门只作辅助层，不等同航班、道路或边境必然开放。
6. **出行目的**：工作、商业、关系、考试或医疗目的按对应模块补充，不让“旅途顺利”替代“办事成功”。
7. **返程**：去程、停留与返程分别判断。

## 禁止

- 用吉门、吉方或吉格保证交通安全、人身安全或顺利入境。
- 用盘面推翻实时天气、灾害、战争、治安、交通中断或官方旅行警示。
- 未核实起点、目的地和现实方位就指定目的地宫。
- 把顺利启程、顺利到达和办事成功混成一个结论。
- 制造精确延误分钟数、事故、失联、到达或返程日期。
- 鼓励用户进入官方明确建议避免或暂勿前往的地区。
