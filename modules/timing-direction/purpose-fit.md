# 事项适配

择时择方必须先加载事项所属模块，不能使用一张“百事皆宜”清单。

| 事项 | 优先加载 |
|---|---|
| 面试、入职、调动、项目启动 | 职业模块 |
| 签约、谈判、交易、开业 | 商业财运模块 |
| 约会、沟通、登记或关系行动 | 感情模块 |
| 考试、报名、提交材料 | 考试模块 |
| 就医、检查、治疗安排 | 健康模块；医疗紧急性优先 |
| 出发、路线、返程 | 出行模块；官方实时信息优先 |

先从专题模块取得主体、事项、机构/对方及成功标准，再观察候选盘是否支持这些核心关系。传统“开休生＋三奇”等一般吉象只能作辅助，不能取代事项适配。

同一候选可能适合沟通、不适合签约；适合启程、不适合办事。输出必须说明“适合做什么”和“不适合做什么”。
