# 择时与方位比较模块 V0.7.3

用于在用户已经提供的多个完整候选时间盘之间比较，或在同一行动时间下比较已明确的候选方向。它不负责起局、补盘或从单一局式推算未来吉时。

## 固定证据链

1. **现实硬约束**：法律、安全、医疗、官方预警、营业/考试时间、交通和参与者可用性。
2. **事项目标**：先确定行动是什么、成功标准和不可接受风险。
3. **主体与专题用神**：由对应职业、感情、商业、考试等模块确定。
4. **候选完整性**：每个时间候选都必须有同体系、同地点口径下的完整盘。
5. **候选方向**：必须有固定参考点、实际方位和可行路线。
6. **结构比较**：主体、事项、目的宫及其关系，再看门、星、神、干和特殊状态。
7. **相对排序**：只在给定候选中比较，不宣称绝对吉时吉方。

## 禁止

- 没有候选完整盘时自行排盘、补盘或编造未来局式。
- 把“事情何时自然发生”的应期问题伪装成择时。
- 只凭吉门、三奇、值符或单一吉格选出候选。
- 忽略主体、事项用神、现实目的和负面结构。
- 强迫从全部不合适或信息不足的候选中选一个“最好”。
- 用吉时吉方保证成功、规避法律责任或覆盖安全/医疗/金融现实。
- 延误急救、报警、撤离、法定期限或其他不可等待的行动。
