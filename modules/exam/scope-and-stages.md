# 问题与考试阶段

先确认考试类型与现实阶段：

| 路由 | 必须明确 |
|---|---|
| 学习准备 | 考试类型、剩余时间、薄弱环节、问状态还是策略 |
| 正式考试 | 尚未考试、正在等待考试，还是已经考完 |
| 成绩/通过 | 问分数、是否过线、排名还是证书通过 |
| 录取 | 录取是否只看分数，是否还有面试、名额、资格审查 |
| 职业测评 | 笔试、实操、面试或综合评估；与岗位结果是否绑定 |

“能不能考上”至少拆成考试表现、过线和最终录取。若存在面试、志愿、名额或资格审查，必须单列，不能由笔试盘面越级推断。

已知事实包括模拟成绩、复习进度、分数线、录取规则、名额、考试完成情况和已发布成绩。盘面不覆盖已经确认的官方结果。
