## 固定证据链

1. **考生**：本人问事通常为日干；代问时按 V0.2 用年命定位目标考生。
2. **考试事项/过程**：时干，表示本次考试、流程或结果事项。
3. **知识与学习能力**：天辅作为文教/学习辅助层，不替代考生。
4. **试卷与外显作答**：景门为试卷/策论/可见表现，丁奇为文章、文字或表达辅助。
5. **评审标准/选拔权**：值符只在考试评分、评委或录取决策明确时启用。
6. **现实门槛**：分数线、名额、资格、规则和实际成绩属于现实数据，盘面不能替代。

必须区分：会不会、能否发挥、答卷质量、是否过线、能否录取。它们不是同一个结论。

## 禁止

- 景门或天辅有利就直接断高分或录取。
- 把考试完成、通过、排名和录取混成“考上”。
- 把古代主考/举子角色机械等同现代阅卷人、学校或系统。
- 为每个科目临时创造不同用神，却无规则来源。
- 根据宫数、河图数等未经验证方法制造精确分数或排名。
- 强行给出成绩发布日期或录取日期。
- 提供作弊、泄题、规避监考或违反考试规则的方法。
