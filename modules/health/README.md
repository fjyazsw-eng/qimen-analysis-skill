# 健康、疾病与就医模块 V0.7

用于健康担忧、已知疾病、就医安排、检查/治疗过程、恢复与照护问题。先完成通用内核和 V0.2 取用，再加载本模块。

## 最高优先级

先运行[安全分流](urgent-escalation.md)。存在急症或安全风险时，立即停止术数分析，转向急救、急诊或现实求助；不得等待排盘、补盘或解盘。

## 固定证据链

1. **安全分流**：是否存在需要立即急救或现实保护的信号。
2. **患者**：本人通常为日干；代问按 V0.2 以可区分年命定位目标患者。
3. **现实医疗事实**：症状、生命体征、检查、诊断、医生意见、处方和病程。
4. **传统疾病信号**：天芮只作术数观察层，不能等同具体疾病。
5. **医疗资源**：天心、乙奇作为传统医者/医疗资源候选，不强行固定为某位医生或某种药。
6. **就医事项**：时干观察本次挂号、检查、治疗或随访过程。
7. **恢复管理**：结合现实复查节点、依从性、支持条件与风险信号讨论行动。

## 绝对禁止

- 根据宫、门、星、神或干支诊断具体疾病、病灶、癌症、怀孕或精神疾病。
- 判断患者必死、寿命、死亡日期，或把生门/死门作字面生死判决。
- 建议停药、换药、加减剂量、拒绝检查、拒绝手术或改变医生方案。
- 用盘面否定已确认的检查、诊断、生命体征或急症表现。
- 为就医、康复或复发制造精确日期和保证。
- 因等待奇门分析而延误急救、急诊、复查或专业心理援助。
