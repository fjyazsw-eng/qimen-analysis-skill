## 固定职业证据链

1. **人**：职业主体，通常为日干；代问或多人按 V0.2 规则定位。
2. **岗位/平台**：开门。传统资料多用于官职、任事；映射现代岗位/组织属于本 Skill 采用的现代解释层。
3. **具体事项/流程**：时干，例如本次求职、调动申请或项目本身。
4. **决策/执行通道**：值符、值使仍按全局规则每局必查；只有存在审批、任命或明确组织权力链时，才进一步把它们升权为职业问题中的权力/执行辅助角色。
5. **关系与落实**：比较核心宫关系、旺衰和特殊状态，分别判断意愿、能力、机会、审批、执行与成本。

这五层不能被压成“开门吉，所以工作吉”。

## 禁止

- 把古代求官直接等同现代求职而不说明转换。
- 把开门同时当现公司、新公司、职位、领导和结果，却不记录角色重叠。
- 看到反吟/马星就断一定调动，看到伏吟就断一定不动。
- 把值符固定为所有公司的老板，或把值使固定为所有 HR。
- 没有区分当前岗位与目标岗位时，强行比较两份工作。
- 把术数判断当作辞职、签约或重大职业决策的唯一依据。
