# 职业专项输出

在通用详细输出中增加以下小节：

```markdown
## 职业问题路由
- 类型：当前工作 / 求职 / 调动 / 晋升 / 项目
- 可验证目标：
- 当前现实阶段：

## 职业角色
- 人（日干/代问主体）：
- 岗位或平台（开门）：
- 事项或流程（时干）：
- 决策条件（值符，按需）：
- 执行通道（值使，按需）：
- 角色重叠与缺失：

## 分层判断
- 本人状态与能力：
- 岗位/平台条件：
- 机会/流程状态：
- 审批与执行：
- 落实程度：

## 职业策略
- 现在最值得推进的环节：
- 应补足的现实条件：
- 不宜过度解读的盘面信号：
```

一句话结论必须同时包含主要机会和主要限制；不能只写“适合/不适合”“能成/不能成”。
