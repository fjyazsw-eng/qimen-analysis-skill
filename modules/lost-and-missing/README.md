# 寻人寻物模块 V0.7.2

用于普通失物、证件/设备遗失、疑似被盗、宠物走失、人员失联或走失。先完成通用内核与 V0.2 取用，再加载本模块。

## 最高优先级

先读取[问题分类与安全分流](scope-and-triage.md)。儿童、认知障碍者、高龄或患病者走失，或存在自伤、暴力、绑架、事故、极端天气等危险迹象时，立即报警并启动现实搜寻，不等待奇门分析，也不存在必须等待 24 小时的规则。

## 固定证据链

1. **安全分流**：是否涉及人身危险、脆弱人员或需要立即报警。
2. **现实最后确认点**：时间、地点、目击、通信、交易、定位和监控。
3. **失主/求测者**：普通失物默认日干；代问时保留求测者身份。
4. **所失对象**：失物默认时干；失联人员优先用本人可区分年命。
5. **搜寻事项**：寻人时以时干观察当前搜寻过程。
6. **传统备选**：六合、甲子戊及其他专题取法单独做敏感性分析。
7. **方向提示**：只能形成现实搜索优先级，不是坐标或事实定位。

## 禁止

- 让高风险寻人等待排盘、补盘、所谓 24 小时或“吉时”再报警。
- 根据玄武、天蓬、宫位或人物类象指控具体人员盗窃、拐骗或藏匿。
- 宣布失联者死亡、被害、被拘禁，或给出精确所在地、距离和时间。
- 为寻找他人提供非法跟踪、入侵账号、窃取定位、私闯或人肉搜索方法。
- 公开未成年人、脆弱人员或无关第三人的敏感身份和位置资料。
- 用术数方向替代监控、平台定位、失物招领、警方或救援机构的线索。
