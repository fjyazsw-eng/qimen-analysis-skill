# 普通失物

## 现实搜索先行

1. 固定最后确认时间、地点和最后使用人。
2. 沿实际动线逐段搜索，联系场所、交通工具和失物招领。
3. 对手机、证件、银行卡、钥匙等先执行官方定位、挂失、冻结或权限保护。
4. 保存监控、交易、门禁和设备定位等真实线索；疑似盗窃时报警。

## 盘面层

- 日干与时干关系：失主与物品是否仍有连接倾向。
- 时干落宫：只生成优先搜索方向与环境类别候选。
- 甲子戊：金钱、财物语境的传统备选。
- 空亡、入墓、反吟等：只作未落实、隐藏、反复等结构提示，不断定找不到或必然复得。
- 玄武：触发“核验误拿/盗失”的现实检查，不指控人员。

不得用宫数换算楼层、房号、公里数或精确取回时间。多个遗失物应分别记录最后使用点，不能默认都在同一位置。
