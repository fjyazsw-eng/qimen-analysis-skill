# 方向与搜索范围

## 参考点必须明确

- 失物：最后确认拥有或使用的位置。
- 走失人员/宠物：最后被可靠目击或定位的位置。

所有方向都相对于参考点表达。参考点不确定时，列出多个现实候选并分别搜索，不把盘面宫位当作参考点。

## 输出限制

- 宫位方向只能给“优先搜索扇区”，不能给精确坐标、楼层、房号或距离。
- 内外盘、旺衰、九天九地等只能形成近/远、显/隐的低置信提示。
- 环境类象只生成核对清单，例如入口、储物区、车辆、座椅附近；不得声称物品或人员必在那里。
- 方向与监控、设备定位、目击或警方线索冲突时，现实线索优先。

搜索计划应按概率和安全性排序：最后确认点 → 实际动线 → 高频放置/停留点 → 可靠线索方向 → 盘面低置信补充区。
