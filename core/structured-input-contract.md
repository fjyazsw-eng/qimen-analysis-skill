# 结构化局式输入契约

本契约适用于“排盘工具已经给出完整局式，Skill 只负责读取和分析”的工作方式。它不要求 Skill 重新排盘。

## 一、现有标准输入可直接接收的字段

### 起局层

- 公历与农历时间、四柱。
- 阴阳遁、局数、节气与上中下元。
- 旬首及所遁六仪。
- 值符星与落宫、值使门与落宫。
- 年、月、日、时空亡与驿马。时家分析中必须保留其时间层来源，不得把年/月/日/时四层空亡或驿马合并成一个无来源的“空亡宫/马星宫”。

### 九宫层

外八宫逐宫应包含：宫名/宫数/五行、八神、九星及其五行、八门及其五行、天盘干、地盘干、必要的寄干、十二长生标注和特殊状态。中五宫允许只记录地盘干与中宫处理方式，不把缺少门、星、神误判为数据不完整。

### 全局标注层

- 原软件明确标出的空亡宫、马星宫必须作为“原局标记”单独保留，不与程序推导层静默合并。
- 时家奇门默认以**时空**作为主空亡层；**日空**保留为辅助层。年空、月空保留在起局基础信息中，普通断局不自动挂入核心宫特殊状态，也不与时空等权计权。专项规则若明确启用其他层级，按专项说明执行。
- 原软件空亡宫若与程序映射的时空不同，只说明“口径/层级不同”，不得自动报成数据冲突；只有同一层级的原始字段与复核结果互相矛盾时才进入冲突轨。
- 驿马同样必须保留年/月/日/时来源；不得把不同时间层的马星合并后重复计权。具体分析权重由问题、专项和时间尺度决定。
- 伏吟、反吟只把**整局成立**的星伏吟、门伏吟、干伏吟、星反吟、门反吟作为全局确定结构输出。单宫星/门回本位或落对宫，不自动标为“局部伏吟”“局部反吟”或“反吟候选”。
- 入墓、击刑及其他特殊结构也使用上述五态，不以未列出自动等同“无”。
- 工具原始标记、程序复核和人工复核必须分列，不覆盖彼此。

## 二、建议排盘工具补充的元数据

以下字段不一定阻断分析，但能显著减少流派和程序口径歧义：

| 字段 | 用途 | 缺失处理 |
|---|---|---|
| `排盘体系` | 明确时家/转盘及拆补、置闰等口径 | 保留默认体系假设并降级 |
| `时区` | 防止起局时间边界误解 | 不重排，只记录未知 |
| `地点` | 仅在时区、真太阳时或方向问题需要时启用 | 普通局势分析可不要求 |
| `八神体系` | 明确白虎、勾陈/朱雀等版本 | 八神名单完整且单一时可作临时识别，否则降级 |
| `天禽处理` | 明确中宫、寄宫或并星规则 | 不自行补天禽 |
| `宫支` | 明示坎子、艮丑寅等宫支 | 缺失时只用固定九宫映射作结构说明 |
| `标注来源` | 区分原局、工具推导、人工复核 | 无来源的派生项降级 |
| `检测状态` | 区分无、未检测、未提供、待复核 | 未说明时按未提供 |
| `工具版本` | 支持同盘复跑和错误追踪 | 不影响当次读取 |

## 三、固定一致性检查

接收局式时只核验，不重新计算：

1. 值符所述星及落宫是否与该宫九星字段一致。
2. 值使所述门及落宫是否与该宫八门字段一致。
3. 外八宫是否各有一个神、星、门、天盘干和地盘干。
4. 中五宫是否声明其特殊处理。
5. 宫内状态与全局状态汇总是否一致；空亡、马星是否保留了年/月/日/时来源层级，原软件标记与程序推导是否分列。
6. 旬首甲干支与所遁六仪是否成对给出。
7. 原局标记与复核标记冲突时，是否明确列出两套结果及来源。
8. 十二长生中的“墓”是否被错误重复标成奇门“入墓”。两者必须分栏。

## 四、五态字段纪律

所有可选字段只允许五种语义：

- **具体值**：工具明确给出。
- **无**：已经检测并确认不存在。
- **未检测到**：程序运行过但不代表人工确认。
- **未提供**：没有数据，不能推定无。
- **待复核**：已有候选结果，但存在口径或一致性问题。

分析时不得把“未提供”写成“无”，也不得把“未检测到”提升为传统规则上的确定不存在。

## 五、收盘回复

当用户提供的提示明确要求只确认读取且没有提出占问事项时，完成最低限度核验后回复：

```text
局式已读取，可以开始提问
```

只有存在会阻止后续定位的问题时，才在该句后追加一条简短的待核验说明；不得提前取用或断局。
