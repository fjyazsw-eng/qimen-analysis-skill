# 输入核验

在解释盘面前判断“能分析到什么程度”。核验只检查完整性、一致性和来源层级，不重新起局。

用户只发盘、尚未定义问题时，本文件仅用于最低限度的收盘核验，不得借核验名义逐宫解释或给出结论；先执行[交互与分析启动协议](interaction-protocol.md)。

结构化文本的字段语义、四态值和一致性检查以[结构化局式输入契约](structured-input-contract.md)为准。

## 字段清单

- **起局层**：起局时间与时区/必要地点、四柱、阴阳遁、局数、排盘法、节气/元、旬首及所遁六仪、值符、值使、空亡、驿马、八神体系和天禽处理方式。
- **九宫层**：外八宫逐宫具备宫名/宫数/五行、八神、九星、八门、天盘干、地盘干。寄干需注明天盘/地盘；中五宫按声明的体系核验，不强求门星神。
- **标注层**：检查星/门的落宫旺衰与月令旺衰、各干十二长生、空亡、入墓、击刑、门迫、伏吟、反吟、马星。每项区分具体值、无、未检测到、未提供、待复核；缺失会限制修正精度。
- **取用上下文层**：本人或代问、求测者现实立场、各人物关系；使用年命时记录出生年干支，甲年命必须有完整干支才能定位所遁六仪。

## 核验输出

1. **已确认**：可直接引用的原始字段。
2. **缺失**：未提供且会限制判断的字段。
3. **冲突**：原始字段内部冲突，或原始数据与标注器不一致。
4. **分析边界**：仍可判断的内容，以及必须暂停或降级的内容。

## 严重度

- **阻断**：九宫不完整、核心宫无法定位、所问主体不明等使取用或关系链失效的问题。停止实质判断，先补资料。
- **限制**：缺月令旺衰、八神/天禽体系不明、特殊状态来源不明等。可以判断主结构，但降低结论精度。
- **提示**：不影响当前问题的非核心字段缺失。记录即可。

字段写成“空”时，先判断其表示空亡、没有值还是未录入；无法判断则按“未提供”处理，不自行补值。

十二长生出现墓、绝、病等只属于干的阶段标注；只有输入另行单列“入墓”时才进入奇门特殊状态。双地支宫的两个长生状态必须原样保留。
