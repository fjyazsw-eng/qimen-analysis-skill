# 输入核验

在解释盘面前判断“能分析到什么程度”。核验只检查完整性、一致性和来源层级，不重新起局。

用户只发盘、尚未定义问题时，本文件仅用于最低限度的收盘核验，不得借核验名义逐宫解释或给出结论；先执行[交互与分析启动协议](interaction-protocol.md)。

## 字段清单

- **起局层**：起局时间与时区/必要地点、四柱、阴阳遁、局数、排盘法、旬首、值符、值使、空亡、驿马。
- **九宫层**：九宫逐宫具备宫名/宫数/五行、八神、九星、八门、天盘干、地盘干。寄干和状态明确写为具体值、`无` 或 `未提供`，不以空白混淆。
- **标注层**：检查星/门的落宫旺衰与月令旺衰、十二长生、空亡、入墓、击刑、门迫、伏吟、反吟、马星。当前版本不要求全部存在，但缺失会限制修正精度。
- **取用上下文层**：本人或代问、求测者现实立场、各人物关系；使用年命时记录出生年干支，甲年命必须有完整干支才能定位所遁六仪。

## 核验输出

1. **已确认**：可直接引用的原始字段。
2. **缺失**：未提供且会限制判断的字段。
3. **冲突**：原始字段内部冲突，或原始数据与标注器不一致。
4. **分析边界**：仍可判断的内容，以及必须暂停或降级的内容。

## 严重度

- **阻断**：九宫不完整、核心宫无法定位、所问主体不明等使取用或关系链失效的问题。停止实质判断，先补资料。
- **限制**：缺月令旺衰、特殊状态来源不明等。可以判断主结构，但降低结论精度。
- **提示**：不影响当前问题的非核心字段缺失。记录即可。

字段写成“空”时，先判断其表示空亡、没有值还是未录入；无法判断则按“未提供”处理，不自行补值。
