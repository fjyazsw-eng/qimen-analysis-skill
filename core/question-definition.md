# 问题定义

先原样记录用户问题，再提炼而不改写其意图：

- 主体：谁在问，是否本人问事或代问。
- 对象：对方、机构、项目、物品或事件。
- 核心动作：现状、能否、是否适合、何时、方向或策略。
- 时间范围：用户关心的现实窗口；未说明则标为未知。
- 已知事实：现实中已发生、可验证且不来自盘面的信息。

“工作怎么样”之类宽泛问题，可以先分析当前总体态势，但不能擅自变成“能否调动”。若不同解释会改变取用、核心宫或应期方法，应先提出一个最小澄清问题。

完成时用一句话写成：`[主体] 想知道 [对象/事情] 在 [时间范围] 的 [状态/结果/策略]。` 同时列出不在本次范围的问题。多个互相独立的问题应分别取用和输出。
