# 取用内核 V0.2

取用决定后续证据是否指向正确对象，优先级高于任何单个吉凶象意。V0.2 采用“角色 → 通用锚点 → 专题候选 → 辅助验证”四层结构，不维护一张脱离问题的万能用神表。

## 必须读取

每次取用读取：

- [角色模型](yongshen/role-model.md)
- [本人、代问与多人](yongshen/subject-and-proxy.md)
- [日干、时干与甲的定位](yongshen/day-hour-and-jia.md)
- [年命使用规则](yongshen/year-life.md)
- [重叠、歧义与降级](yongshen/collisions-and-ambiguity.md)
- [取用记录格式](yongshen/decision-record.md)

问题涉及明确类别时，再读[问题路由与候选用神](yongshen/question-router.md)。发生规则争议或需要审计来源时，再读[取用资料说明](../references/yongshen-sources.md)。

## 决策顺序

1. 原样保留问题，识别求测者、问事主体、对方、事情、机构及中介角色；角色不存在就不强行创建。
2. 判断本人问事、代问还是多人关系。
3. 以日干/时干建立通用锚点，再按问题类型加入经确认的专题候选。
4. 年命、值符、值使及其他符号只在其角色理由成立时加入，不因“盘里有”就自动取用。
5. 为每个用神标记主用/辅用、规则编号、来源等级、落宫和备选方案。
6. 处理同宫、同符号多角色、甲遁定位、信息不足和流派差异。
7. 取用不稳定时做条件式双轨分析，不继续输出单一确定结论。

## 固定原则

- 本人亲自问自己的现实事项，默认以天盘日干为本人主锚点（YS-G01）。
- 一般事项默认以天盘时干为事体锚点（YS-G02）；存在更直接的专题用神时，时干保留为事情过程/当下状态，不自动取代专题用神。
- 年命属于身份与人物区分层，不机械替代日干（YS-G03）。
- 对方与事情是两个语义角色；即使都暂取时干，也必须声明角色重叠（YS-G04）。
- 六爻世应只能用于解释关系，不得转写为奇门规则（YS-G05）。
- 取用结果是分析选择，不能伪装成原始盘面事实（YS-G06）。
