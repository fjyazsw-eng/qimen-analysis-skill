# 角色模型

取用先解决“盘中这个符号代表谁/什么”，再分析吉凶。角色是问题语义，不是固定符号。

## 六类角色

| 角色 | 含义 | 是否必有 |
|---|---|---|
| 求测者 | 发起本次问题、提供局式的人 | 是 |
| 问事主体 | 结果直接落在谁身上 | 是；可与求测者相同 |
| 对方 | 与主体互动的具体人或一方 | 否 |
| 事情/客体 | 所问项目、任务、货物、结果载体等 | 是 |
| 机构/裁决者 | 单位、规则制定者、审批或裁判角色 | 否 |
| 中介/连接 | 介绍、撮合、传递或经纪角色 | 否 |

“我”必须拆解成求测者与问事主体。本人问事时两者重合；代问时两者分开。结果不是独立用神，而是从主体、事情及其关系中综合推断。

## 用神层级

- **主用**：直接回答该角色核心状态，缺失会改变主结论。
- **辅用**：验证身份、补充过程或提供专题侧面，不能单独推翻主用。
- **候选**：规则或信息尚不足，仅用于敏感性分析。

同一符号可以承担多个角色。重叠本身就是信息结构，不得为了让表格好看而另造代表。

## 来源等级

- **A**：项目采用体系内、可定位到传统文献的明确专题规则。
- **B**：跨多个成熟传统/现代体系稳定使用的通用规则，作为本 Skill 默认口径。
- **C**：常见现代实战经验或尚有流派分歧的候选。
- **D**：本次问题中的临时假设，只能条件式使用。

来源等级表示规则依据，不表示预测一定准确。
