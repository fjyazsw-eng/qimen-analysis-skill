# 日干、时干与甲的定位

## 默认落宫口径

- **YS-G01（B）**：本人亲自问事，以天盘日干落宫为本人主锚点。
- **YS-G02（B）**：一般事项以天盘时干落宫为事体/当下过程锚点。
- 查找天盘干时包含明确标注的寄干；若目标干是寄干，记录“寄干落宫”，不伪装成普通主干。
- 地盘同名干是该宫结构的一部分，不自动替代天盘日干/时干的人事角色。

时干可以在具体问题中代表对方、货物或被告等角色，但这是专题语义。若同时代表事体与对方，按角色重叠处理，不选择性隐藏其中一项。

## 甲遁映射（YS-J01，A）

奇门盘中六甲隐于六仪。当天干角色为甲时，必须依据完整干支定位：

| 甲干支 | 所遁六仪 |
|---|---|
| 甲子 | 戊 |
| 甲戌 | 己 |
| 甲申 | 庚 |
| 甲午 | 辛 |
| 甲辰 | 壬 |
| 甲寅 | 癸 |

原始角色仍写“甲”，定位字段写“遁于某仪”。例如：`日干甲辰 → 以壬所在的天盘位置定位`。这属于读取遁甲映射，不是重新排盘。

只有“甲”而缺少支时，六种映射无法唯一确定，标为阻断性取用缺失。不得默认甲等于值符，也不得任选六仪。

## 日时同符号/同宫（YS-J02）

日干与时干落同宫时，保留“人事同宫”的结构；分别读取角色，但共享同一宫环境。不可另选一个宫制造人事分离。关系分析应说明五行宫关系无法提供方向性，需要依靠宫内结构、专题用神及其他高层证据。
