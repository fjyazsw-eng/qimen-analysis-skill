# 重叠、歧义与降级

## 常见重叠

- 日干与时干同宫：人、事共享环境，不另造宫。
- 对方与事情都暂取时干：声明同符号双角色，专题用神仅作补充。
- 日干与年命同干/同宫：当前角色层与身份层叠合，不重复计算成两票证据。
- 两个人年命相同：只能分析共同宫状态，不能仅凭该干区分个体。
- 专题用神与日干/时干同宫：分别解释角色，共享宫级事实，避免重复堆叠同一证据。

## 歧义等级

- **可解释**：角色重叠但不影响定位。继续分析并说明。
- **限制性**：存在两个合理候选，会影响局部关系。做 A/B 双轨敏感性分析。
- **阻断性**：主体、甲遁映射或关键人物无法定位。暂停相关结论，先补信息。

## 双轨输出（YS-A01）

```text
方案 A：角色 → 用神 → 采用理由 → 得出的关系
方案 B：角色 → 用神 → 采用理由 → 得出的关系
不变结论：两种方案都支持的部分
敏感结论：会随取用改变的部分
需要补充：能排除其中一个方案的信息
```

不得把两个方案的有利信息拼在一起形成一个看似更完整的结论。
