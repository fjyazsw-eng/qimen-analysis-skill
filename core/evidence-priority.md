# 证据优先级

从高到低：

1. **取用正确性**：人物和事情定位错误会使后续分析失去对象；以 V0.2 取用决策记录中的角色、规则编号、重叠和备选方案为准。
2. **核心宫整体结构**：宫/宫支、门、星、神、天地盘干、寄干、干间关系及组合形成主体结构；使用覆盖账本防止遗漏和重复计权。
3. **核心宫之间关系**：生克比和、资源流向与互动方向。
4. **旺衰与阶段力量**：门星宫/月旺衰修正表达能力，各干十二长生修正阶段；两者不混成分数。
5. **特殊状态**：空亡、入墓、击刑、门迫、伏吟、反吟、马星等修正落实与变化方式。
6. **八神等辅助象意**：补充心理、氛围或表现方式。
7. **细节象意与经验判断**：仅作低权重线索，需标明经验性质。

低层证据不能单独推翻更高层结构。同层证据相反时，比较与问题的直接相关性、完整度、力量与特殊状态。结论可标记依据编号，如 `E2 核心宫 + E3 宫间关系`，方便案例回归。传统定义、现代解释和实战经验必须分别标注。
