# 盘内寻机与趋吉避凶策略引擎

本文件是预测转化为现实决策的唯一权威规则源。策略必须来自已经完成并冻结的状态、动力、预测与盘内证据，不提供脱离证据的万能化解法。**解局权不拥有改判权**：发现可利用路径不得反向改写原始定性、主趋势或已冻结应期。

## 一、四类目标

策略层先判断当前属于哪类任务，可并存但必须有主次：

1. **减凶**：削弱主要阻力、降低损失、缩小风险暴露。
2. **转吉**：补足原本缺失的资源、渠道、关系、能力或落实条件，使平/偏凶结构获得改善条件。
3. **增吉**：在原本有利的结构上放大有效优势，提高兑现效率并防止吉势被折损。
4. **寻生**：主路径明显受阻时，寻找替代路径、第三方变量、次级通道或可等待的触发条件。

## 二、先冻结自然趋势，再进入寻机

进入本层前必须已经完成：取用、核心宫、宫际关系、旺衰与特殊状态、状态层、动力层、未来预测；需要应期时先完成候选应期。先记录“若不额外干预，最可能怎样发展”，再讨论可改变变量。

- **不可控**：政策、对方最终决定、市场环境、天气、客观限制。用于设置情景、风险和失效条件。
- **可控**：行动时间、节奏、沟通、投入、渠道、合作对象、路线/方位、资源配置、备选与止损。策略优先优化这些变量。

## 三、盘内寻机扫描

核心矛盾明确后，扫描A级核心宫之外的B级相关宫，寻找能够改变核心证据链的候选变量。候选宫至少满足下列一项，才有资格进入“候选生机/转化宫”：

- 能**生扶主体或关键成事用神**，补足明显不足；
- 能**泄、制、转移主要阻力**，且不会制造更高等级的新风险；
- 能在主体与目标之间形成可解释的**生克中介链**；
- 能补齐已经识别出的**资源、渠道、协作、信息、资金、执行或承接条件**；
- 主路径受阻时，能够代表现实中确实存在的**替代通道、第三方或下一节点**。

不得因为某宫有生门、开门、六合、三奇或其他传统吉象，就自动认定为生机宫。先有“它如何改变核心矛盾”的关系证据，再读门星神干。

## 四、候选路径验证

每个候选解法必须依次通过：

1. **关系成立**：与核心宫的生克、资源流向或角色链真实存在。
2. **类象匹配**：门、星、神、干的现实映射与所需解决变量一致，不牵强套象。
3. **力量可用**：门与星同时检查落宫旺衰、月令旺衰；必要时结合干的阶段状态。
4. **落实检查**：空亡、入墓、击刑、门迫、伏吟、反吟、马星等是否使方案难兑现、反复或成本过高。
5. **现实可执行**：现实中存在对应人物、资源、行为或渠道；法律、安全、专业要求与成本允许。

任何一层证据不足，都必须降级为“候选路径”，不得包装成确定化解法。

## 五、从盘象翻译为现实动作

八门可作为行动方式候选，但必须结合完整宫象：

- 休门：缓和、休整、关系维护、降低节奏；
- 生门：补资源、收益、成长、承接能力；
- 伤门：竞争、执行、切割、技术性突破；
- 杜门：保密、收口、控制信息、技术处理、暂缓表态；
- 景门：文书、表达、展示、材料、传播、证据呈现；
- 死门：收尾、终止、舍弃、固定、处理旧问题；
- 惊门：预警、反馈、风险暴露、快速信息刺激；
- 开门：打开渠道、谈判、工作机会、公开推进。

以上不是固定吉凶表。伤、杜、死、惊在与目标匹配时也可成为合适工具；生、开、休、景若失令、受制或与核心矛盾无关，也不得机械采用。九星用于补充能力/功能，八神用于补充表现方式、关系和隐性环境，三奇六仪及已核实格局只作组合修正。

## 六、值符值使在策略层的使用

每局必先检查值符和值使。值符用于识别全局主导力量/权力背景，值使用于识别主要运行通道；与主用神、辅用神、核心宫或候选转化宫直接相关时升权，不相关时保留为背景。不得把值符固定等同某个领导，也不得把值使固定等同某个流程岗位。

## 七、择时择方的位置

时间和方位属于增强层，不是第一层解法。只有在目标事件、参考点、方向宫、现实路线或候选时间明确时才使用。先回答“改变哪个现实变量”，再讨论何时、何方更利于执行。现实安全、法律、医疗和可达性优先；不得以走方位、摆物、等待吉时替代必要现实行动。

## 八、策略输出

每条建议统一使用：

`目标（减凶/转吉/增吉/寻生） → 建议 → 盘内转化链 → 现实依据 → 适用条件 → 验证信号 → 停止/切换条件`

有多个现实方案时，按收益、阻力、风险、时机、资源消耗、成功条件进行可解释比较；不使用不透明总分。优先给1～3条真正可执行的策略。

## 九、禁止

- 看到吉门就直接建议去对应方位。
- 用“化解”承诺必然改变结果。
- 为了找到解法而修改原预测、原取用或原证据权重。
- 用低相关宫的漂亮象意推翻核心宫和宫际关系。
- 把术数建议替代医疗、法律、重大投资、人身安全等现实必要措施。
