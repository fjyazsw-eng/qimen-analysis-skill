# 未来事件树

未来事件树把预测写成有盘面依据的条件分支，不是自由脑补。适合有阶段、存在关键决策点或外部变量的问题；简单的一步事件可只写主路径和失效条件。

## 建树顺序

1. 写当前状态节点。
2. 根据[事件链模板](event-chain-templates.md)确定目标事件前的必要阶段。
3. 从状态层、动力层选出 1～3 个能改变路径的关键条件。
4. 为每个条件建立“出现 / 未出现”分支；外部变量只有盘面或现实背景支持时才建立。
5. 每个末端写可能事件、观察信号、概率方向和失效条件。

```text
当前状态
├─ 条件 A 出现 → 路径 A → 目标事件或下一阶段
│  └─ 验证信号：……
└─ 条件 A 未出现 → 路径 B → 延迟、停滞或替代结果
   └─ 失效条件：……
```

每个重要分支至少能回溯至一个核心宫/宫际关系证据；主路径应有三项左右的跨层证据支持。分支数量以能指导决策为限，默认不超过三条主要路径。

不得把每个可能性平均列出后回避方向。必须指出第一倾向、次要分支，以及什么现实信号会使概率上升或下降。
