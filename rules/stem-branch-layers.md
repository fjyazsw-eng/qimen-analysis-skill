# 天干、地支与十二长生层

本规则处理结构化输入已经给出的干支信息，不重新起局。

## 一、盘层分工

- **天盘干**：当前运作、外显行动和变化层。
- **地盘干**：基础、背景、承载和原有条件层。
- **寄干**：附加角色或次级条件；必须注明天盘寄干或地盘寄干。
- **四柱干支**：用于记录起局时间、旬首、空亡、马星及专题明确启用的时间关系；不自动把八字式干支关系混入每个宫。

## 二、天盘干与地盘干关系

先按五行记录天盘对地盘的关系：

| 关系 | 结构含义 |
|---|---|
| 天盘生地盘 | 当前行动向基础投入、维护或消耗 |
| 地盘生天盘 | 基础为当前行动提供资源 |
| 天盘克地盘 | 当前行动试图改变、控制或突破基础 |
| 地盘克天盘 | 基础条件制约当前行动 |
| 比和 | 表里同类，可能协同，也可能重复或竞争 |

该关系必须结合干所承担的现实角色、宫门星神、旺衰和特殊状态翻译，不能单独定吉凶。

## 三、十干克应边界

天盘干加地盘干可以形成传统十干克应。只有规则库已有可核对来源的组合才能命名；没有已维护条目时，只使用五行关系和盘层分工，不凭记忆补口诀。

命名克应后仍需检查门、星、宫、旺衰、迫墓击刑及问题场景。传统名称属于结构证据，不是结果保证。

## 四、十二长生

十二长生描述干在宫支或标注口径下的阶段状态。使用纪律：

1. 只读取工具给出的结果及口径，不自行覆盖。
2. 长生、帝旺等不自动等于事情成功；病、死、墓、绝也不自动等于失败或现实灾病。
3. 用于修正该干所承担角色的活跃度、成熟度、可见度或收束程度。
4. 双地支宫保留两个状态，按[宫位综合规则](palace-synthesis.md)处理。
5. 十二长生的“墓”是阶段标注；奇门“入墓”是单列特殊结构。输入未单列入墓时，不得自行合并。

## 五、地支关系边界

当前输入主要通过四柱、宫支、空亡、驿马和十二长生携带地支信息。只有专题规则明确需要日支、时支、年命支、方位支或应期支时，才分析合、冲、刑、害等关系。普通宫位综合不自动套入整套八字地支关系，防止体系混杂。

固定宫支映射只用于识别输入结构：

| 宫 | 宫支 |
|---|---|
| 坎一 | 子 |
| 艮八 | 丑、寅 |
| 震三 | 卯 |
| 巽四 | 辰、巳 |
| 离九 | 午 |
| 坤二 | 未、申 |
| 兑七 | 酉 |
| 乾六 | 戌、亥 |
| 中五 | 无固定单一宫支，按输入体系处理 |

映射用于理解“丑衰/寅病”等双标注，不用于反推或改写原盘。

## 六、甲与旬首

六甲隐于六仪，甲的定位继续遵守取用内核中的完整甲干支映射。输入同时给出“旬首甲辰壬”时，保留甲辰与壬的对应；不得把甲直接当作盘面可见干，也不得只看“甲”忽略其支。
