# 宫位关系

先依据核心宫五行记录方向，再结合双方整体强弱解释现实互动。

| 关系 | 基础解释 | 必须继续检查 |
|---|---|---|
| 我生对方/事情 | 我方输出、支持或投入 | 能否持续投入，是否形成消耗 |
| 对方/事情生我 | 对方向我方提供条件 | 支持是否真实、稳定且能落实 |
| 我克对方/事情 | 我方尝试约束、取得或控制 | 我方是否够强，控制成本是否过高 |
| 对方/事情克我 | 我方受约束、压力或规则限制 | 压力来源、承受能力及缓冲 |
| 比和 | 同类、协同或竞争 | 目标、力量及同类资源争夺 |

“生”不自动等于有利，“克”不自动等于失败。必须回答谁主动、推动、付出、消耗、控制、依赖，以及谁在旺衰和特殊状态修正后更有执行力。
