# 定性评价

本文件是正式分析开头的唯一权威定性规则源，并受[分析稳定性与冻结协议](analysis-stability.md)约束。通过正式分析门控后，必须先给用户 4～8 行大白话定性，再展开证据；收盘建档、补问确认、复盘和纯教学不使用本段。

## 固定格式

```markdown
【定性评价】

等级：
一句话：
核心判断：
建议：
```

等级只能使用：`大吉 ＞ 吉 ＞ 小吉 ＞ 平偏吉 ＞ 平 ＞ 平偏凶 ＞ 小凶 ＞ 凶 ＞ 大凶`。

## 形成方法

先完成内部分析，再把结论前置，不可只凭门、星、旺衰或特殊状态定级。至少综合：取用是否稳定、核心宫整体、宫际动力、落实条件、未来路径、主要风险和可改变变量。

- `大吉/吉/小吉`：主要动力与落实条件较完整；等级随阻力、代价和稳定性下调。
- `平偏吉`：支持略强，但仍依赖明确条件或时机。
- `平`：支持与阻力实质接近，或目标尚未形成方向；不得用来逃避判断。
- `平偏凶/小凶`：阻力更强，但仍有可调整路径。
- `凶/大凶`：高权重证据共同指向明显不利、代价高或风险不可接受；仍不得表述为必然失败。

等级表示当前时空条件下的总体有利程度，不等于成功率，也不替代风险等级。若当前与后势不同，写成“小吉，但不宜激进”或“平偏凶，但可调整”，并点明关键条件。

同盘同问复跑必须保持等级稳定。正式定级前必须先完成稳定性协议中的“证据账本 + 五问方向闸门”；只有盘面更正、问题主体/目标/范围改变、新局修正或 Skill 版本规则变更足以改变证据链时才可调整，并明确说明原因。现实行情变化不得反向修改已经冻结的卦象定性。
