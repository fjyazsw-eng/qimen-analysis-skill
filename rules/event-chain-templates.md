# 专项事件链模板

本文件只定义现实阶段，不改变统一取用与证据规则。预测前先把目标事件放到链中的明确节点；节点不是自动应期。

| 专项 | 典型事件链 |
|---|---|
| 感情发展 | 认识 → 联系 → 持续互动 → 确定关系 |
| 复合 | 重新联系 → 缓和 → 处理旧问题 → 重新确定关系 |
| 工作调动/晋升 | 机会/表态 → 沟通 → 决策 → 审批 → 文件 → 到岗/落实 |
| 求职 | 投递 → 面试 → 反馈 → offer → 入职 |
| 商业项目 | 机会 → 谈判 → 决策 → 签约 → 资金/资源 → 启动/交付 |
| 一般投资/交易 | 建仓/观察 → 震荡 → 启动 → 加速 → 转折 → 兑现/止损 |
| 股票十日走势 | 蓄势/承压 → 启动 → 延续或加速 → 转折 → 整理/再选择方向 |
| 考试/录取 | 准备 → 应试 → 评分 → 公布 → 录取/资格落实 |
| 出行 | 准备 → 出发 → 途中 → 抵达 → 办事/返程 |
| 寻人寻物 | 线索 → 缩小方位/范围 → 搜寻 → 确认 → 找到/安全交接 |
| 消息/审批 | 内部讨论 → 表态 → 审核 → 通知 → 正式生效 |

用户的目标事件可能跳过或增加现实节点，应按背景修正。不得把“想到、讨论、收到线索”写成“联系、批准、找到”等更晚阶段的命中。
