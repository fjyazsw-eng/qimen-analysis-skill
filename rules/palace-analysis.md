# 宫位分析

每个核心宫使用统一观察表，保证跨案例可比。

| 层 | 读取内容 | 现实问题 |
|---|---|---|
| 宫 | 宫位、五行、宫支与基础环境 | 主体处在什么位置与承载条件中？ |
| 门 | 行为通道、事情呈现方式、宫/月旺衰 | 事情通过什么方式发生，通道有多大表达力？ |
| 星 | 能力、功能、作用倾向、宫/月旺衰 | 主体以何种能力处理事情，能力能否发挥？ |
| 神 | 氛围、心理或隐显特征 | 行为如何表现，哪些线索可辅助理解？ |
| 天盘干 | 外显、变化、当前运作及十二长生 | 当前在做什么、处于何种阶段？ |
| 地盘干 | 基础、背景、承载及十二长生 | 底层条件是什么、能否承载？ |
| 寄干 | 盘层、附加结构及十二长生 | 是否承担用神或提供次级条件？ |
| 干间关系 | 天盘与地盘的生克/比和及已核实克应 | 当前行动与基础如何互动？ |

随后按特殊状态和全局关联修正。先分别陈述各层，再综合；不把某个符号的固定关键词直接当成现实结论。基础象意见[门星神干规则](door-star-deity-stem.md)，完整覆盖和防重复计权见[宫位综合规则](palace-synthesis.md)。
