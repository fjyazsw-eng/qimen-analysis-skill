# 宫位分析

每个核心宫使用统一观察表，保证跨案例可比。

| 层 | 读取内容 | 现实问题 |
|---|---|---|
| 宫 | 宫位、五行与基础环境 | 主体处在什么位置与承载条件中？ |
| 门 | 行为通道、事情呈现方式 | 事情通过什么方式发生或受阻？ |
| 星 | 能力、功能与作用倾向 | 主体以何种能力处理事情？ |
| 神 | 氛围、心理或隐显特征 | 行为如何表现，哪些线索可辅助理解？ |
| 天盘干 | 外显、变化或当前运作线索 | 当前在做什么、如何变化？ |
| 地盘干 | 基础、背景或承载线索 | 底层条件是什么？ |
| 寄干 | 附加结构 | 是否提供额外但非主导的信息？ |

随后按旺衰和特殊状态修正。先分别陈述各层，再综合；不把某个符号的固定关键词直接当成现实结论。门、星、神、干的系统象意库当前仅保留[接口](door-star-deity-stem.md)，尚未定稿。
