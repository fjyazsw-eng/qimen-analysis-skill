# 多局连续比较

同一现实问题在 T1、T2、T3 多次起局时，把它们视为局势演化，不作多数表决。先确认问题、主体、目标事件、体系和时间尺度可比；定义改变时先说明，不强拼一条时间线。

## 比较清单

逐局使用相同口径检查：主用、辅用、宫际关系、门、星、神、旺衰、空亡、入墓、击刑、马星、六合等关系指标、值符值使、事情用神，以及原应期是否被强化或削弱。

固定输出：

```markdown
【旧预测】
【不变信号】
【增强信号】
【减弱信号】
【反转信号】
【新增变量】
【对应修正】强化 / 削弱 / 修正 / 推迟 / 提前 / 反转
```

必须解释变化可能来自现实事件、人物态度、时间推进、用户行动、环境、问题定义或取用变化。若无法定位原因，保留旧预测并降低新结论置信度。

## 前测冻结

旧局形成后，立即在[预测台账](../cases/prediction-ledger.md)冻结起局时间、问题、主辅用、定性、趋势、目标事件、窗口、策略、失效条件和置信度。新局不得改写旧记录，只能新增带时间戳的比较记录。

现实结果出现后，按复盘协议区分事前预测、结果和后验发现。原预测未写过的符号解释只能标为【后验发现】，不得计为命中。
