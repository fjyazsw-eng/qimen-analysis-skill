# 门、星、神、干基础象意与使用边界

本文件提供稳定的最低解释基线，不是穷尽所有古籍克应。每个符号先按问题映射，再受宫位、旺衰、天地盘关系和特殊状态修正。

## 信息层级

1. **传统结构层**：名称、五行、所在宫、门宫生克、星门得令失令、值符值使身份及有来源的克应。
2. **现代解释层**：把传统功能翻译为现实中的通道、能力、氛围、资源与行动方式。
3. **经验细节层**：具体人物、物品、身体、颜色或事件类象，仅在专题规则有依据且不越过安全边界时使用。

下表属于现代解释基线，不冒充古籍原句，也不能单项决定结果。

## 八门基础功能

| 门 | 最低功能解释 | 常见过程维度 |
|---|---|---|
| 休门 | 休整、交流、关系维护、缓和 | 是否适合等待、协商、恢复 |
| 生门 | 生长、资源、收益、形成 | 条件能否增长并落实 |
| 伤门 | 行动、竞争、损耗、受伤 | 推进代价、冲突与执行强度 |
| 杜门 | 闭合、保密、阻隔、技术性处理 | 信息是否封闭、流程是否受阻 |
| 景门 | 展示、信息、文书、名声与表现 | 是否被看见、表达是否有效 |
| 死门 | 终止、停滞、封存、收束 | 是否进入结束、僵化或处置阶段 |
| 惊门 | 惊扰、口舌、突发、波动 | 风险感、争议和反应速度 |
| 开门 | 开放、机会、职位、机构与开始 | 入口、许可、平台和可操作空间 |

八门的专题角色由模块决定。例如开门在职业问题中可代表岗位/平台，但不能在所有问题中固定等于工作。

## 九星基础功能

| 星 | 最低功能解释 | 常见过程维度 |
|---|---|---|
| 天蓬 | 流动、冒险、欲望、复杂策略 | 风险承受、隐性动机、流动性 |
| 天任 | 承担、稳定、务实、持续 | 承载力、责任和稳定推进 |
| 天冲 | 冲劲、行动、速度、突破 | 启动能力、推进速度与冲动 |
| 天辅 | 辅助、学习、规划、传播 | 学习力、方案、支持与协同 |
| 天英 | 表达、显现、声誉、热度 | 曝光、表现和名声成本 |
| 天芮 | 问题、缺陷、照护、负担 | 待处理处、修复与服务需求 |
| 天柱 | 阻隔、口舌、支撑、破坏性压力 | 沟通阻力、结构压力与坚持 |
| 天心 | 判断、管理、技术、医药候选 | 决策质量、专业性和精细处理 |
| 天禽 | 中央、统合、承载、协调 | 汇总、居中与寄宫关系 |

天芮、天心等在健康场景只可作为传统结构线索，不能据此诊断具体疾病。

## 八神基础功能

| 神 | 最低功能解释 | 权重纪律 |
|---|---|---|
| 值符 | 核心、权力、标准、关键条件 | 仅在问题确有权力/主导角色时提升 |
| 螣蛇 | 缠绕、虚惊、想象、反复信息 | 用于不确定性，不证明欺骗或精神问题 |
| 太阴 | 隐蔽、细致、内部支持、筹划 | 补充隐显与支持方式 |
| 六合 | 连接、合作、协调、关系纽带 | 不直接等于感情成功或合同成立 |
| 白虎 | 压力、强硬、损耗、迅速处置 | 不据此断伤灾、疾病或暴力事实 |
| 玄武 | 隐情、流动、信息不透明、遗失风险 | 不据此指控盗窃、欺骗或犯罪 |
| 九地 | 稳、慢、低、实、隐藏与承载 | 修正速度、位置和落实方式 |
| 九天 | 高、远、快、扩张、公开与行动 | 修正范围、速度和外显程度 |

若输入采用勾陈、朱雀等不同神盘体系，必须先声明版本，不把名称静默替换为白虎、玄武体系。

## 十干最低功能基线

十干首先承担取用角色和盘层关系，其次才使用象意：

| 干 | 五行/阴阳 | 最低功能解释 |
|---|---|---|
| 甲 | 阳木 | 核心、主干、领导与开端；盘中按六仪定位 |
| 乙 | 阴木 | 柔性、生长、协调、细节与转圜 |
| 丙 | 阳火 | 显明、扩散、公开、推动与声势 |
| 丁 | 阴火 | 精细、表达、文书、技术与持续关注 |
| 戊 | 阳土 | 资源、资本、承载、规模与现实基础 |
| 己 | 阴土 | 组织、整理、内部条件、约束与弯曲 |
| 庚 | 阳金 | 阻力、执行、强制、变化与对抗 |
| 辛 | 阴金 | 精细、规则、修正、错误与敏感处 |
| 壬 | 阳水 | 流动、变化、扩散、连接与大范围过程 |
| 癸 | 阴水 | 隐微、细流、内部信息、迟滞与渗透 |

这些功能只帮助把“天盘正在怎样运作、地盘具有什么基础”说清楚。十干克应、三奇六仪格局和专题角色仍以已维护规则为准。

## 组合使用

每个核心宫必须完成：

```text
门的通道 × 星的能力 × 神的表现 × 天盘干的当前运作 × 地盘干的基础
→ 旺衰修正 → 特殊状态修正 → 与其他核心宫关系 → 现实问题翻译
```

若某层与问题无直接关系，覆盖账本标记“保留”，不得为了显得详细而强行制造结论。完整方法见[宫位综合分析](palace-synthesis.md)和[干支层](stem-branch-layers.md)。
