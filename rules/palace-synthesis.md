# 宫位综合分析与覆盖账本

本规则确保核心宫的每项已提供信息都被检查，但不把所有信息等权相加，也不要求把无关细节全部写进用户可见结论。

## 一、核心宫特征向量

每个核心宫依次建立以下记录：

| 层 | 必查字段 | 影响维度 |
|---|---|---|
| 宫体 | 宫位、五行、宫支、内外与方位（按需） | 环境、承载、位置 |
| 门 | 本义、问题映射、宫旺衰、月旺衰、门迫 | 行为通道、执行方式 |
| 星 | 本义、问题映射、宫旺衰、月旺衰 | 能力、功能、持续性 |
| 神 | 本义、问题映射 | 氛围、显隐、表现方式 |
| 天盘干 | 干本义、五行、十二长生、角色 | 当前运作、外显变化 |
| 地盘干 | 干本义、五行、十二长生、角色 | 基础条件、底层承载 |
| 寄干 | 所在盘层、五行、十二长生、是否承担用神 | 附加角色或次级条件 |
| 干间关系 | 天盘对地盘的生克、同类及已核实克应 | 表层与基础如何互动 |
| 特殊状态 | 空亡、入墓、击刑、门迫、马星及其他 | 落实、受限、变化方式 |
| 全局关联 | 是否为值符/值使宫，是否受伏吟反吟等影响 | 背景、权力或执行通道 |

## 二、覆盖账本

正式分析在内部为每个核心宫建立账本：

```text
字段 → 输入值 → 作用对象 → 影响维度 → 证据级 → 已采用/保留/冲突/不适用 → 结论去向
```

- **已采用**：直接参与某个结论槽位。
- **保留**：信息有效，但与当前问题相关性低，不进入主结论。
- **冲突**：存在来源或规则分歧，进入敏感性说明。
- **不适用**：该问题不启用此信息的专题含义。

“综合考虑”是完成账本并说明取舍，不是让每个符号都产生一句断语。

## 三、稳定综合顺序

1. 用神和问题决定分析哪些宫，禁止先看吉凶再反选用神。
2. 宫、门、星、神、干分别描述，不在单层提前定成败。
3. 天地盘干关系与核心宫之间关系描述互动方向。
4. 门星旺衰及干的十二长生只修正表达能力和阶段。
5. 空亡、入墓、击刑、门迫、伏反吟、马星修正落实与变化。
6. 值符值使和全局结构只在与问题角色相关时提升权重。
7. 将结果落入固定结论槽位：状态、动力、阻力、主动方、落实度、不确定性和建议。

## 四、防止重复计权

- 值符星既作为宫内九星又作为全局值符时，事实只记录一次；“星的功能”和“值符身份”分属两个解释维度，不重复投票。
- 值使门同理。
- 门迫既出现在宫内状态又出现在全局汇总时，只作一次修正。
- 十二长生“墓”不等同于奇门入墓，不得叠加两次。
- 同一空亡由日时或工具多处重复给出时，只保留来源，不重复削弱。

## 五、双地支宫位

艮、巽、坤、乾各含两个地支。输入若分别给出两支对应的十二长生：

1. 原样保留两个状态，不平均、不投票、不挑较吉者。
2. 当前问题能定位到具体方位、人物支或触发支时，才启用对应一支。
3. 无法定位时写成“宫内存在双状态，具体落点未解析”，只形成不确定性，不强行合成单一旺衰。

坎、震、离、兑为单支宫；若工具只给长生状态而未写支，可按固定宫支记录其结构来源，但不得借此重新排盘。

## 六、非核心宫

不机械逐断九宫。非核心宫只有在以下情况下进入：承担专题用神、与核心宫形成必要链条、承载值符值使且问题涉及权力/流程、用户追问方向/应期，或用于解释明确冲突。其余宫位完成输入核验即可，避免制造无关结论。
